Kitamasa 算法是一种用于快速计算线性递推数列第 N 项的算法。它的名字来源于提出者 Kitamasa。

```
Kitamasa 矩阵是一个特殊的矩阵，只有第一行有值，所以不用像普通矩阵这样求所有矩阵位置的乘法
```

解决什么问题
对于形如 f(n) = c1*f(n-1) + c2*f(n-2) + ... + ck*f(n-k) 的递推关系，当 N 非常大（如 10^18）时，Kitamasa 能在 O(k^2 log N) 时间内算出 f(N)。

和矩阵快速幂的关系
矩阵快速幂同样能解决这个问题，但复杂度是 O(k^3 log N)，因为每次矩阵乘法是 O(k^3)。Kitamasa 的核心优化在于：不直接对矩阵做快速幂，而是对多项式做快速幂。

核心思想
引入符号 x 代表一次转移，那么 x^n 就代表转移 n 次。

递推关系对应一个特征多项式 P(x) = x^k - c1*x^(k-1) - ... - ck。

计算 x^n mod P(x)，得到一个次数小于 k 的多项式 R(x)。

R(x) 的系数就是 f(n) 用初始 k 项表示的线性组合系数，即 f(n) = sum(ri * f(i))。

对于斐波那契，特征多项式是 x^2 = x + 1，所以 x^n mod (x^2-x-1) 得到的就是用 f(0) 和 f(1) 表示 f(n) 的系数。

复杂度
朴素多项式乘法和取模：O(k^2 log N)

用 FFT/NTT 加速多项式运算：O(k log k log N)

所以在你之前的问题中，用 Kitamasa 就是在多项式环上做快速幂，比矩阵快速幂少一个 k 的因子。
