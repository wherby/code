```
 def solve(x):
        if x < 2 * k: return xn[x]
        
        v = solve(x // 2)
        tag = x % 2
        
        res = [0] * (2 * k)
        
        for i in range(k):
            for j in range(k):
                res[i + j + tag] += v[i] * v[j]
                res[i + j + tag] %= mod
        
        ans = [0] * k
        
        for i in range(2 * k):
            for j in range(k):
                ans[j] += res[i] * xn[i][j]
                ans[j] %= mod
        
        return ans
```


这个 `solve(x)` 函数的核心，是用**多项式取模（Polynomial Modulo）**的性质来实现**多项式快速幂**。

简单来说：**`solve(x)` 的目标是求出 $x^{x}$ 模特征多项式 $P(y)$ 后的余式系数向量**。它的推理过程可以分为三步：

---

### 一、 第一步：把数列项转化为多项式

对于递推关系 $F_n = \sum_{i=1}^k a_i F_{n-i}$，我们可以定义特征多项式：


$$P(y) = y^k - \sum_{i=1}^k a_i y^{k-i}$$

在代数中，数列下标平移 1 位（$F_n \to F_{n+1}$）等价于多项式乘上 $y$。
因此，求 $F_{x+1}$ 在基底 $(F_1, F_2, \dots, F_k)$ 上的线性表示系数，**完全等价于**求多项式 $y^x$ 在模 $P(y)$ 意义下的余式：

$$y^x \equiv v_0 + v_1 y + v_2 y^2 + \dots + v_{k-1} y^{k-1} \pmod{P(y)}$$

返回值数组 `v = [v_0, v_1, ..., v_{k-1}]` 就是 $y^x \bmod P(y)$ 的系数向量。

---

### 二、 第二步：倍增卷积（对应代码中的 `v[i] * v[j]`）

我们要求 $y^x \bmod P(y)$，利用二进制快速幂的思想：
令 $x = 2 \cdot \lfloor x/2 \rfloor + \text{tag}$（其中 $\text{tag} = x \bmod 2$）。

那么：


$$y^x = \left(y^{\lfloor x/2 \rfloor}\right)^2 \cdot y^{\text{tag}}$$

假设我们已经通过递归 `v = solve(x // 2)` 知道了 $y^{\lfloor x/2 \rfloor} \bmod P(y)$ 的展开式：


$$y^{\lfloor x/2 \rfloor} \equiv \sum_{i=0}^{k-1} v_i y^i \pmod{P(y)}$$

现在把它**平方并乘以 $y^{\text{tag}}$**：


$$y^x \equiv \left( \sum_{i=0}^{k-1} v_i y^i \right) \left( \sum_{j=0}^{k-1} v_j y^j \right) \cdot y^{\text{tag}} \pmod{P(y)}$$

展开这个乘积：


$$\left( \sum_{i=0}^{k-1} v_i y^i \right) \left( \sum_{j=0}^{k-1} v_j y^j \right) \cdot y^{\text{tag}} = \sum_{i=0}^{k-1} \sum_{j=0}^{k-1} (v_i \cdot v_j) \, y^{i + j + \text{tag}}$$

这正是代码中这一段双重循环在做的事情（多项式乘法 / 卷积）：

```python
for i in range(k):
    for j in range(k):
        res[i + j + tag] += v[i] * v[j]
        res[i + j + tag] %= mod

```

乘完之后，`res` 数组保存的就是多项式展开后最高达 $2k-1$ 次的各项系数。

---

### 三、 第三步：降次截断/余式还原（对应代码中的 `res[i] * xn[i][j]`）

卷积展开后得到的多项式 `res` 次数最高达到了 $2k-1$，超过了我们需要的 $k-1$ 次。
因此必须对 $P(y)$ **重新取模降次**。

此时预处理好的 `xn` 矩阵就发挥作用了：

* `xn[i]` 保存的是 $y^i \bmod P(y)$ 的系数向量（对任意 $0 \le i < 2k$）。

所以，最高 $2k-1$ 次的多项式 $\sum_{i=0}^{2k-1} \text{res}[i] \cdot y^i$ 模 $P(y)$ 的结果，就是把每一项 $y^i$ 换成它的模余式 `xn[i]`，然后线性累加：

$$y^x \bmod P(y) = \sum_{i=0}^{2k-1} \text{res}[i] \cdot \Big( y^i \bmod P(y) \Big) = \sum_{i=0}^{2k-1} \text{res}[i] \cdot \mathbf{xn}[i]$$

这正是代码中第二段循环在做的事情：

```python
ans = [0] * k

for i in range(2 * k):
    for j in range(k):
        ans[j] += res[i] * xn[i][j]
        ans[j] %= mod

```

这样就把最高 $2k-1$ 次的多项式重新“压缩”回了只有 $k$ 项（次数 $0 \sim k-1$）的向量 `ans` 中！

---

### 总结推导全貌

$$\begin{aligned} y^x &= \left( y^{\lfloor x/2 \rfloor} \right)^2 \cdot y^{x \bmod 2} \\ &\equiv \left( \sum_{i=0}^{k-1} v_i y^i \right)^2 \cdot y^{\text{tag}} \pmod{P(y)} && \text{(1. 递归求得 } v \text{)} \\ &= \sum_{i=0}^{2k-1} \text{res}[i] \cdot y^i && \text{(2. 双重循环做卷积得到 } \text{res} \text{)} \\ &\equiv \sum_{i=0}^{2k-1} \text{res}[i] \cdot \mathbf{xn}[i] \pmod{P(y)} && \text{(3. 利用预处理的 } \text{xn} \text{ 降次得到 } \text{ans} \text{)} \end{aligned}$$

这种方法在数学和算法竞赛中被称为 **Bostan-Mori** 或 **多项式快速幂（Chowla-Fiduccia 算法）**，能将原本矩阵快速幂 $O(k^3 \log x)$ 的复杂度优化到 $O(k^2 \log x)$。

```
怎么理解RES 是2*k 维向量，这里基向量不是只有K维码？
```

这个问题问到了点子上！

**`res` 确实只是一个临时的“中间产物”，它的 $2k$ 维并不是因为“基底变成了 $2k$ 维”，而是因为“两个 $k-1$ 次多项式相乘后，最高次数变为了 $2k-2$（加上 `tag` 后最高达到 $2k-1$）”。**

我们可以从以下三个层次来透彻理解：

---

### 1. 为什么 `res` 需要 $2k$ 的空间？（多项式乘法展开）

在递归求解 $y^{\lfloor x/2 \rfloor} \bmod P(y)$ 时，我们得到了一个只有 $k$ 项（次数从 $0$ 到 $k-1$）的余式多项式 $V(y)$：


$$V(y) = v_0 + v_1 y + v_2 y^2 + \dots + v_{k-1} y^{k-1}$$

现在我们要计算它的**平方并乘以 $y^{\text{tag}}$**（对应 $y^x = (y^{\lfloor x/2 \rfloor})^2 \cdot y^{\text{tag}}$）：


$$R(y) = \left( \sum_{i=0}^{k-1} v_i y^i \right) \cdot \left( \sum_{j=0}^{k-1} v_j y^j \right) \cdot y^{\text{tag}}$$

* 当 $i = k-1$ 且 $j = k-1$ 时，最高次项为 $y^{(k-1) + (k-1) + \text{tag}} = y^{2k - 2 + \text{tag}}$。
* 当 $\text{tag} = 1$ 时，**最高次方达到 $y^{2k-1}$**。

一个最高次方为 $2k-1$ 的多项式，共有 $2k$ 个系数（对应 $y^0, y^1, y^2, \dots, y^{2k-1}$）。
因此，**`res` 的长度设为 $2k$，纯粹是为了能够装下这个未取模前的“乘积多项式”的 $2k$ 个系数。**

---

### 2. 基底永远只有 $k$ 维，高次项是如何被“折叠”回去的？

虽然乘完之后多项式膨胀到了 $2k-1$ 次，但**特征多项式 $P(y)$ 的次数只有 $k$ 次**（定义为 $y^k = \sum_{i=1}^k a_i y^{k-i}$）。

这意味着：**任何大于等于 $k$ 次的高次项 $y^k, y^{k+1}, \dots, y^{2k-1}$，都可以根据递推公式降次，重新用前 $k$ 个基底 $(y^0, y^1, \dots, y^{k-1})$ 来线性表示！**

这正是预处理数组 `xn` 的作用：

* `xn[0]` 对应 $y^0 \bmod P(y)$ $\rightarrow$ 维数为 $k$ 的基底向量
* `xn[1]` 对应 $y^1 \bmod P(y)$ $\rightarrow$ 维数为 $k$ 的基底向量
* $\dots$
* `xn[2k-1]` 对应 $y^{2k-1} \bmod P(y)$ $\rightarrow$ **维数依然为 $k$ 的基底向量**（在预处理的第一步里已经把它们降次回前 $k$ 项了）

---

### 3. 第二个循环做的事情：把 $2k$ 维的“未取模多项式”投影回 $k$ 维基底空间

看代码的第二部分：

```python
ans = [0] * k

# res[i] 是第 i 次项 y^i 的系数
# xn[i] 是 y^i 模 P(y) 之后在 k 维基底上的投影向量
for i in range(2 * k):
    for j in range(k):
        ans[j] += res[i] * xn[i][j]
        ans[j] %= mod

```

* `res[i]` 只是一个**纯标量系数**，表示 $y^i$ 这一项乘以了多少。
* `xn[i]` 是一个**长度为 $k$ 的向量**，表示 $y^i$ 降次后在 $k$ 个标准基底上的分配权重。

这一步的数学本质就是：


$$\text{向量 } \mathbf{ans} = \sum_{i=0}^{2k-1} \text{res}[i] \cdot \mathbf{xn}[i]$$

这里是将 $2k$ 个标量系数，乘以各自对应的 **$k$ 维基底向量 $\mathbf{xn}[i]$**，最终重新**压缩/投影**回了一个 $k$ 维的向量 `ans` 中。

---

### 总结对照

| 变量 | 物理意义 | 维度 / 长度 | 解释 |
| --- | --- | --- | --- |
| **`v`** | 递归子问题的余式多项式系数 | $k$ 维 | 次数最高为 $k-1$ |
| **`res`** | 两多项式相乘展开后的**临时多项式系数** | $2k$ 维 | 未取模，次数可高达 $2k-1$ |
| **`xn[i]`** | $y^i$ 模 $P(y)$ 后的**基底向量** | $k$ 维 | 无论 $i$ 多大，降次后永远只有 $k$ 项 |
| **`ans`** | `res` 模 $P(y)$ 后的**最终余式向量** | $k$ 维 | 将 `res` 的 $2k$ 项全部用 `xn` 降次合并后的 $k$ 维结果 |

**完全正确！你抓到了非常核心且精妙的一点！**

这里的 $2k$ 维数组 `res`，在代数本质上就是**前 $2k$ 个自然基底 $\{y^0, y^1, y^2, \dots, y^{2k-1}\}$ 的线性组合系数**。

我们可以把你的这个深刻理解拆解为以下三点：

---

### 1. `res` 的每个位置代表“多项式阶数”

如你所说，数组 `res` 的第 $i$ 个位置 `res[i]`，记录的就是**第 $i$ 阶项 $y^i$ 的系数**：

* `res[0]` 对应 $y^0$（第 0 阶）
* `res[1]` 对应 $y^1$（第 1 阶）
* $\dots$
* `res[2k-1]` 对应 $y^{2k-1}$（第 $2k-1$ 阶）

在没有做模 $P(y)$ 降次之前，**多项式的阶数最高会相乘扩展到 $2k-1$ 阶**。因此，必须用一个长度为 $2k$ 的向量来完整承载这 $0 \sim 2k-1$ 阶的系数。

---

### 2. 基底向量的对应关系

如果把 $y^i$ 本身看作一个基底，那么在 $2k$ 维的空间中：

* 第 0 阶 $y^0$ 对应的就是向量 $[1, 0, 0, \dots, 0]$（只有第 0 位为 1）
* 第 1 阶 $y^1$ 对应的就是向量 $[0, 1, 0, \dots, 0]$（只有第 1 位为 1）
* $\dots$
* 第 $2k-1$ 阶 $y^{2k-1}$ 对应的就是向量 $[0, 0, \dots, 0, 1]$（只有第 $2k-1$ 位为 1）

多项式卷积的过程：


$$\text{res} = \sum_{i=0}^{2k-1} \text{res}[i] \cdot y^i$$


本质上就是在这 $2k$ 个未降次的“阶数基底”上做线性组合。

---

### 3. 为什么只需要预处理到 $2k-1$ 阶（`xn` 矩阵）？

这也正好解释了为什么代码一开始只预处理了长度为 $2k$ 的 `xn` 矩阵（即 `xn[0]` 到 `xn[2k-1]`）：

因为在倍增乘法中，**任意两个 $k-1$ 阶的多项式相乘，再乘上 $y^{\text{tag}}$（$\text{tag} \in \{0, 1\}$），产生的新多项式最高阶数绝对不会超过 $2k-1$ 阶**！

因此：

1. **$0 \sim k-1$ 阶**：本身就是目标基底，`xn[i]` 形式为单位阵（即 `xn[0] = [1,0,...]`, `xn[1] = [0,1,...]`）。
2. **$k \sim 2k-1$ 阶**：虽然超过了 $k-1$ 阶，但我们在预处理时，已经把这几阶的 $y^i \bmod P(y)$ 的结果**提前翻译/映射**回了 $k$ 维的线性表示。

当卷积计算出 $2k$ 维的 `res` 之后，代码直接做一次矩阵乘法：


$$\mathbf{ans} = \sum_{i=0}^{2k-1} \text{res}[i] \cdot \mathbf{xn}[i]$$

这就相当于将 $2k$ 维空间中的阶数向量，通过映射矩阵 `xn`，**线性投影**回了由前 $k$ 阶构成的 $k$ 维目标基底空间！

**是的，这完全就是线性代数中典型的“升维”与“降维”操作！**

如果用空间变换的视角来审视整个 `solve(x)` 算法，它的全过程可以非常漂亮地画成一个**升维再降维**的闭环：

```
k 维空间 (余式向量 v)
   │
   │  【升维】做多项式卷积 (v ⊗ v) 
   ▼
2k 维扩展空间 (未取模系数 res)
   │
   │  【降维】模 P(y) 线性投影 (res · xn)
   ▼
k 维空间 (最终余式向量 ans)

```

---

### 1. 升维：从 $k$ 维跨越到 $2k$ 维（信息的完全表达）

* **为什么升维？**
在 $k$ 维空间中（即由 $y^0, y^1, \dots, y^{k-1}$ 撑起的向量空间），向量内做加法和数乘是封闭的，但**向量内部的分量做乘法（多项式卷积）会导致次数相加**。
$k-1$ 次项与 $k-1$ 次项相乘，会产生最高 $2k-2$ 次（带上 `tag` 可达 $2k-1$ 次）的新项。
* **升维的实质**：
在 $k$ 维空间里“装不下”乘法产生的高次项信息了，因此算法显式地将空间**扩张/升维到 $2k$ 维**（即用 $0 \sim 2k-1$ 阶基底构成的向量 `res`），用来完整无损地容纳这个乘法卷积的结果。

---

### 2. 降维：从 $2k$ 维投影回 $k$ 维（利用约束压扁空间）

* **为什么降维？**
我们最终只需要知道它模特征多项式 $P(y)$ 后的余式，而余式**必须且只能**存在于 $k$ 维空间中。
* **降维的约束方程**：
特征多项式 $P(y) = 0$ 实际上给这个 $2k$ 维空间施加了 $k$ 个线性约束方程（即 $y^k = \sum a_i y^{k-i}$）。
* **降维的实质（线性投影）**：
矩阵 `xn`（大小为 $2k \times k$）就是一个**降维投影矩阵**（基底变换矩阵）。
代码中的 `ans[j] += res[i] * xn[i][j]`，本质上就是把 $2k$ 维空间里的一个点 `res`，沿着约束平面的方向，线性投影（降维）回 $k$ 维目标子空间，得到了降维后的坐标 `ans`。

---

### 总结

你抓住了代数结构的核心：

1. **倍增卷积** = **升维**（$k \to 2k$），用更高的自由度接住乘法产生的高阶交叉项。
2. **取模降次** = **降维**（$2k \to k$），利用特征方程提供的约束，把高维坐标投影折叠回低维空间。

整个 `solve(x)` 快速幂算法，就是不断在 $k$ 维和 $2k$ 维之间进行“升维运算 $\to$ 降维投影”的循环，直到算完所有二进制位！
