### 一、 为什么关注“不包含峰值”反而极其简单？

如果直接去数“包含峰值的子数组”，你会发现很难在线段树或树状数组中合并，因为：

* 了一个峰值？包含了两个峰值？还是包含了三个峰值？
* 峰值是在子数组的左边、中间还是右边？
组合情况会发生爆发式的重叠与交叉，极难用简单的状态去合并。

但如果**反过来，看“什么时候不可能有峰值”**，问题就会发生奇迹般的简化：

两个在数组中**相邻的峰值点** $p_m$ 和 $p_{m+1}$（例如下标 3 和下标 7）：

* 在 $p_m$ 和 $p_{m+1}$ 之间的所有元素（下标 3, 4, 5, 6, 7），**内部绝对不可能再有任何第三个峰值**。
* 因此，只要一个子数组 $[i, j]$ 的左右端点**完全落在区间 $[p_m, p_{m+1}]$ 内部**（即 $p_m \le i < j \le p_{m+1}$），**这个子数组就绝对不可能是峰值子数组！**

---

### 二、 区间组合的本质：用“缝隙组合”填满整个区间

对于查询区间 $[l, r]$，假设区间内包含了 $k$ 个峰值点 $p_1, p_2, \dots, p_k$。

这些峰值点就像几把刀，把大区间 $[l, r]$ 切割成了 $k+1$ 个**互不重叠（仅在边界峰值点处相交）的“绝对无峰缝隙”**：

```text
[l ...... p1] [p1 ...... p2] [p2 ...... p3] ...... [pk ...... r]
|<- 左端缝隙 ->| |<------- 中间缝隙 ------->|        |<- 右端缝隙 ->|

```

每个缝隙 $[A, B]$ 的长度为 $Len = B - A + 1$。
在这个缝隙内部，**任意挑两个点作为左端点和右端点，构成的所有子数组都绝对没有峰值**。

一个长度为 $Len$ 的缝隙，内部包含的无峰子数组组合数就是简单的等差数列求和（组合数）：


$$f(Len) = \frac{Len \times (Len + 1)}{2}$$

---

### 三、 算法如何用树状数组 / 线段树做区间组合？

因为“缝隙”的形式高度统一，整个大区间 $[l, r]$ 内所有**绝对没有峰值的组合数**，就是所有缝隙的组合数直接相加（再扣除边界重叠）：

1. **左端缝隙组合**：$\frac{(p_1 - l + 1)(p_1 - l + 2)}{2}$（只有左端点 $l$ 和第一个峰值 $p_1$ 决定）
2. **右端缝隙组合**：$\frac{(r - p_k + 1)(r - p_k + 2)}{2}$（只有最后一个峰值 $p_k$ 和右端点 $r$ 决定）
3. **中间所有缝隙组合**：$\sum f(p_{m+1} - p_m + 1)$

线段树或树状数组所做的唯一一件事，就是**把这些“相邻峰值缝隙的组合数 $f(p_{m+1} - p_m + 1)$”当作基础数据单元存储起来**。

* 当区间查询 $[l, r]$ 时，算法只需要：
1. 算出大区间 $[l, r]$ 的**所有可能子数组组合总数** $f(r - l + 1)$。
2. 用线段树/树状数组快速把中间所有缝隙的无峰组合数**累加起来**。
3. 用总数减去无峰组合数，剩下的**就必定是至少包含一个峰值的合法组合**。
