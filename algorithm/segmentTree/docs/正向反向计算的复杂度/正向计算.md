# 正向计算

$$\text{Ans} = h \cdot (a[1] - l) - a[0] \cdot (a[0] - l) - a[2]$$
```
这个公式的意义是什么？
```


要理解这个公式的物理意义，我们可以把它拆解为 **“全集” - “非峰值缝隙的多余面积”** 的空间几何映射。

如果我们把子数组的左端点 $i$ 当作**横坐标**，右端点 $j$ 当作**纵坐标**，那么区间 $[l, h]$ 内所有合法的子数组 $(i, j)$（满足 $l \le i \le j \le h$），在直角坐标系中就对应着一个**网格区域**。

把公式重新写成几何分割的形式，它的物理意义就会极其直观：

$$\text{Ans} = \underbrace{h \cdot (p_k - l)}_{\text{矩形 A}} - \underbrace{p_1 \cdot (p_1 - l)}_{\text{矩形 B}} - \underbrace{\sum_{m=1}^{k-1} p_{m+1} \cdot (p_{m+1} - p_m)}_{\text{缝隙多余矩形 C}}$$

---

### 一、 核心物理模型：三块矩形的“排他性覆盖”

假设在询问区间 $[l, h]$ 内，存在 $k$ 个峰值 $p_1, p_2, \dots, p_k$。一个子数组包含峰值，意味着它的边界必须满足：**左端点 $i \le p_k$，且右端点 $j \ge p_1$**。

#### 1. 第一项 $h \cdot (p_k - l)$：包含峰值的**最大潜在控制区（大矩形 A）**

* **物理意义**：这是假定“右端点最远可以伸展到 $h$”时，允许左端点落在 $[l, p_k]$ 范围内的所有**组合容量**。
* **几何对应**：一个横跨宽度为 $(p_k - l)$、高度为 $h$ 的大矩形面积。

#### 2. 第二项 $- p_1 \cdot (p_1 - l)$：扣除**左侧非法区（矩形 B）**

* **物理意义**：虽然左端点落在 $[l, p_1)$ 看起来合法，但如果右端点还没延伸到第一个峰值 $p_1$（即 $j < p_1$），这个子数组内部就**没有任何峰值**。
* **几何对应**：从大矩形中切除掉左下角那个“右端点不够长”的无峰矩形，其宽度为 $(p_1 - l)$，高度投影限制为 $p_1$。

#### 3. 第三项 $- a[2]$，即 $-\sum p_{m+1} \cdot (p_{m+1} - p_m)$：扣除**相邻峰值间的“无峰死角”（矩形 C）**

* **物理意义**：这是整个公式最绝妙的地方！
对于任意相邻的两个峰值 $p_m$ 和 $p_{m+1}$，如果一个子数组的左端点越过了 $p_m$（$i > p_m$），但右端点又没达到 $p_{m+1}$（$j < p_{m+1}$），那么这个子数组就**完全掉进了两个峰值之间的缝隙里**，内部不含任何峰值。
* **代数转化为几何**：
每一个缝隙造成的非法子数组组合数，在二维坐标系上精确对应一个**面积为 $p_{m+1} \times (p_{m+1} - p_m)$ 的小矩形**！
把所有相邻缝隙的非法矩形面积全部加起来，就是 $a[2]$。

---

### 二、 为什么物理意义是 $p_{m+1} \cdot (p_{m+1} - p_m)$？（代数降维的精妙之处）

你可能会好奇，为什么无峰缝隙的组合数（通常是组合数公式 $\frac{Len(Len+1)}{2}$）变成了一个简单的**矩形乘积 $p_{m+1} \cdot (p_{m+1} - p_m)$**？

这就是代数消去律（Telescoping Sum）在物理空间上的体现：

* 传统的几何容斥是去数“三角形”（因为 $i \le j$ 是半个正方形，即三角形）。
* 但当我们将大直角三角形的面积公式展开，并与所有缝隙的小直角三角形面积相减时，**所有的二阶平方项（$x^2$）和常数项在相减的过程中全部相互抵消了**！
* 抵消后，原本倾斜的“阶梯状三角形面积”，被代数变形重新拼贴成了一块块**边长平直的矩形面积**。

---

### 三、 物理意义总结

这个组合公式的物理意义可以概括为：

> **“用一个覆盖全区间的最大矩形包络（矩形 A），精准裁剪掉左端点落空区（矩形 B）以及所有相邻峰值之间的无峰死角矩形（$a[2]$），剩下的净面积就是包含峰值的子数组总数。”**

它成功地把一个复杂的“二维区间包含关系统计”，翻译成了**线段树上可以无缝拼接的“矩形面积累加”**。

我们可以将所有可能的子数组 $(i, j)$（$l \le i \le j \le h$）映射到二维平面直角坐标系中：

* **横轴 $i$** 表示子数组的左端点下标。
* **纵轴 $j$** 表示子数组的右端点下标。

因为子数组必须满足 $i \le j$，所以所有合法的子数组落在主对角线 $j = i$ 的**左上方**。

通过代数变换后，公式 $\text{Ans} = \underbrace{h \cdot (p_k - l)}_{\text{矩形 A}} - \underbrace{p_1 \cdot (p_1 - l)}_{\text{矩形 B}} - \underbrace{\sum p_{m+1} \cdot (p_{m+1} - p_m)}_{\text{缝隙多余矩形 C}}$ 在坐标系中表现为**大矩形 A 减去若干个无峰填充矩形**的几何图形：

```text
纵轴 j (右端点)
^
|
h +---------------------------------------+  <-- 矩形 A 的顶边 (j = h)
| |                                       |
| |              【包含峰值的              |
| |              合法子数组区域】           |
| |                                       |
| +-------------------+                   |
| |                   |                   |
| |  缝隙矩形 C2       |                   |
| | (p3 * (p3 - p2))  |                   |
| +-------------------+                   |
| |                   |                   |
| |  缝隙矩形 C1       |                   |
| | (p2 * (p2 - p1))  |                   |
p1+-------------------+-------------------+  <-- 矩形 B 的顶边 (j = p1)
| |                   |
| |    矩形 B         |   (此区域外部为 j < i 的非法区)
| | (p1 * (p1 - l))   |
| |                   |
l +-------------------+-------------------+-------------------> 横轴 i (左端点)
  l                  p1                  pk                   h

```

### 各矩形区域的几何与物理映射解析

#### 1. 矩形 A（底框背景）：$h \cdot (p_k - l)$

* **边界范围**：横轴 $i \in [l, p_k]$，纵轴 $j \in [0, h]$。
* **几何含义**：这是一个宽为 $(p_k - l)$、高为 $h$ 的大矩形。它代表了**把左端点限定在有效峰值控制区 $[l, p_k]$ 内时，右端点向上能延伸到的最大容积**。

#### 2. 矩形 B（底座扣除项）：$- p_1 \cdot (p_1 - l)$

* **边界范围**：横轴 $i \in [l, p_1]$，纵轴 $j \in [0, p_1]$。
* **几何含义**：位于矩形 A 的底部左下角。这里的子数组右端点 $j < p_1$，**还没延伸到第一个峰值 $p_1$**，因此完全不包含峰值，必须从矩形 A 中整体扣除。

#### 3. 缝隙矩形 C（中间扣除项）：$- a[2] = -\sum_{m=1}^{k-1} p_{m+1} \cdot (p_{m+1} - p_m)$

* **边界范围**（以第 $m$ 个缝隙为例）：
* 横轴区间为 $i \in [p_m, p_{m+1}]$，宽度为 $(p_{m+1} - p_m)$。
* 纵轴高度延伸至 $j = p_{m+1}$。


* **几何含义**：这些矩形像阶梯一样叠在矩形 B 之上。
对于左端点已经跨越 $p_m$（$i > p_m$），但右端点还未到达 $p_{m+1}$（$j < p_{m+1}$）的所有点 $(i, j)$，它们**刚好掉进了相邻峰值 $p_m$ 与 $p_{m+1}$ 之间的无峰缝隙中**。

---

### 为什么消去后形成了平直的“矩形”而不是“三角形”？

在常规几何求和中，由于 $j \ge i$ 的限制，有效区域边界通常是倾斜的三角形。

但在将“三角形组合数公式”与“代数消去”结合后：

1. **对角线上的三角形半区**在总数与缝隙数相减的过程中**互相抵消**。
2. 复杂的阶梯状边界被**重新组合拼接**成了一个个边长平直的矩形块（即 $p_{m+1} \times (p_{m+1} - p_m)$）。

这种几何上的“化斜为直”，正是线段树能够用简单的三元组 `(p1, pk, acc)` 在 $O(1)$ 时间内完成区间合并的核心原因！

你抓得非常准！这正是代数推导最神奇、也最反直觉的地方：**为了在线段树中得到极简的结合律公式，我们人为地扩展出了“虚构区域”，再用几何项把“虚构区”与“无峰区”一次性全部抵消掉了。**

如果严格按照物理限制 $i \le j$（左端点 $\le$ 右端点），图形在二维坐标系中应该只分布在**主对角线 $j = i$ 的左上方（下三角区域完全为空）**。

但如果强行在“下三角梯形”上做线段树合并，公式就会极其复杂（必须同时维护区间长度、多项式二阶项等）。

### 一、 严格限制 $i \le j$ 的“物理真实图”

在真实的子数组定义中，任意点 $(i, j)$ 必须位于对角线 $j = i$ 上方（绿色区域）：

```text
纵轴 j (右端点)
^
|
h +-----------------------------------+
| |                                  /|
| |       合法的子数组区域          / |
| |    (含峰值，且满足 i <= j)    /   |
| |                              /    |
| +-----------------------------+     |
| |                            /|     |  <-- 缝隙 C2
| +---------------------------+ |     |
| |                          /| |     |  <-- 缝隙 C1
| +-------------------------+ | |     |
p1|                        /| | |     |  <-- 矩形 B
| |  【非法的下三角区】   / | | |     |
| |     (j < i)        /  | | |     |
l +-------------------+---+-+-+-----+--> 横轴 i (左端点)
  l                  p1  p2 p3 pk    h
                       / / / /
                     / / / /   <-- 对角线 j = i

```

如果只看上三角，边界是倾斜的阶梯状，线段树根本无法用简单乘法合并。

### 二、 为什么公式里的矩形越过了对角线？（代数抵消真相）

代码中的公式：


$$\text{Ans} = \underbrace{h \cdot (p_k - l)}_{\text{矩形 A}} - \underbrace{p_1 \cdot (p_1 - l)}_{\text{矩形 B}} - \underbrace{\sum p_{m+1} \cdot (p_{m+1} - p_m)}_{\text{缝隙矩形 C}}$$

它实际上做了一次“先假想补充、再代数抵消”的巧妙操作：

```text
纵轴 j
^
|
h +----------------------------+  <-- 矩形 A 顶边 (j = h)
| |\\\\\\\\\\\\\\\\\\\\\\\\\\\\|
| |\\  【纯粹的合法子数组区】  |
| |\\\\\\\\\\\\\\\\\\\\\\\\\\\\|
| +------------+---------------+
| |            |               |
| |  缝隙矩形  |               |  <-- 矩形 C (包含了对角线下方的虚构区)
| +------------+               |
p1|            |               |
| |  矩形 B    |               |  <-- 矩形 B (包含了对角线下方的虚构区)
| |            |               |
l +------------+---------------+--> 横轴 i
  l           p1              pk
  |<-- 宽 -->|

```

看这些矩形在**对角线下方 ($j < i$)** 的重叠情况：

1. **大矩形 A**：它的底部一直延伸到了 $j = 0$。因此，它**把对角线下方 $j < i$ 的非法虚构区域也当成面积算进去了**。
2. **扣除项 矩形 B**：它的底部也延伸到了 $j = 0$。它不仅扣除了 $j < p_1$ 的无峰子数组，**顺便把矩形 A 在 $i \in [l, p_1]$ 范围内多算的下三角虚构面积也一起扣掉了**！
3. **扣除项 缝隙矩形 C**：每一个 $p_{m+1} \times (p_{m+1} - p_m)$ 的小矩形，底部同样延伸到了 $j = 0$。它不仅扣除了相邻峰值间的无峰子数组，**顺便把矩形 A 在 $i \in [p_m, p_{m+1}]$ 范围内多算的下三角虚构面积也全部扣掉了**！

---

### 三、 总结：代数的奇迹

这就是为什么你在图形里看到矩形越过了 $i \le j$ 的边界：

> **大矩形 A 在对角线下方多算了多少“虚构面积”，矩形 B 和所有缝隙矩形 C 就在对角线下方精准地扣除了多少“虚构面积”。**

* **在对角线下方 ($j < i$)**：$\text{矩形 A 的虚面积} - \text{矩形 B 的虚面积} - \text{缝隙矩形 C 的虚面积} \equiv 0$（完全抵消）。
* **在对角线上方 ($j \ge i$)**：剩下的恰好就是**真实包含峰值的子数组数量**！

这种“借用下三角虚构空间来凑平直矩形”的技巧，是高阶算法推导中将“几何阶梯问题”转化为“标量纯乘法代数式”的最核心精髓。
