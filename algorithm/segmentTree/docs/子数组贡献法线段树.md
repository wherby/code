给你一个下标从 0 开始的整数数组 nums 。

定义 nums 一个子数组的 不同计数 值如下：

令 nums[i..j] 表示 nums 中所有下标在 i 到 j 范围内的元素构成的子数组（满足 0 <= i <= j < nums.length ），那么我们称子数组 nums[i..j] 中不同值的数目为 nums[i..j] 的不同计数。
请你返回 nums 中所有子数组的 不同计数 的 平方 和。

子数组指的是一个数组里面一段连续 非空 的元素序列。



```
外循环是求到i为右端点的所有子数组的累积，为什么只需要和上一个出现点有关？上一个出现之前的贡献就不计算了吗？
```

这是一个**非常经典且非常深刻**的疑问！

答案是：**“上一个出现点之前的贡献”并没有被丢弃，它们已经被原封不动地保留并继承了下来！**

我们来看看为什么只需要对 $[j+1, i]$ 这个区间进行更新和计算。

---

### 一、 核心逻辑：从 $i-1$ 变到 $i$ 时发生了什么？

假设当前右端点扩展到了 $i$，新加入的数字是 $x = \text{nums}[i]$。这个数字上一次出现的位置是 $j$。

我们把以 $i$ 为右端点的所有子数组，按照起点 $k$ 划分为**两部分**：

#### 1. 第一部分：起点 $k \le j$ 的子数组（$k \in [0, j]$）

* 这些子数组是：$\text{nums}[0..i], \text{nums}[1..i], \dots, \text{nums}[j..i]$。
* **特点**：它们内部**本来就已经包含过**数字 $x$ 了（因为在位置 $j$ 处就有一个 $x$）。
* **结果**：再在末尾补上一个 $x$，这些子数组的“不同数字个数”**完全没有变化**！

$$\text{现在的不同计数 } f[k] = \text{之前的不同计数 } f[k]$$


* **对平方和的增量**：增量为 $0$。

#### 2. 第二部分：起点 $k > j$ 的子数组（$k \in [j+1, i]$）

* 这些子数组是：$\text{nums}[j+1..i], \dots, \text{nums}[i..i]$。
* **特点**：它们内部**之前从未出现过**数字 $x$。
* **结果**：在末尾补上 $x$ 后，这些子数组的“不同数字个数”**全部严格 $+1$**！

$$\text{现在的不同计数 } f[k] = \text{之前的不同计数 } f[k] + 1$$


* **对平方和的增量**：根据增量公式，每一个子数组的平方增加 $(2 \cdot f[k] + 1)$。

---

### 二、 变量 $s$ 是如何变化的？

变量 $s$ 代表的是：**“以当前 $i$ 为右端点的所有子数组的平方和”**。

在加入 $a[i]$ 之前，$s$ 代表的是**以 $i-1$ 为右端点**的所有子数组的平方和：


$$s_{\text{旧}} = \sum_{k=0}^{i-1} (f_{\text{旧}}[k])^2$$

当右端点变成 $i$ 后，新的平方和 $s_{\text{新}}$ 可以拆成两部分：

$$\begin{aligned} s_{\text{新}} &= \sum_{k=0}^{i} (f_{\text{新}}[k])^2 \\ &= \underbrace{\sum_{k=0}^{j} (f_{\text{旧}}[k])^2}_{\text{起点 } k \le j \text{（完全没变）}} + \underbrace{\sum_{k=j+1}^{i} (f_{\text{旧}}[k] + 1)^2}_{\text{起点 } k > j \text{（全部 } +1 \text{）}} \end{aligned}$$

注意到，第一部分（$k \le j$）的数值**直接继承了上一步计算好的结果**，根本不需要重新算一遍！

我们需要增加的，**仅仅是第二部分（$k > j$）产生的“额外增量”**：

$$s_{\text{新}} = s_{\text{旧}} + \sum_{k=j+1}^{i} \Big( 2 \cdot f_{\text{旧}}[k] + 1 \Big)$$

---

### 三、 直观对比例子

假设数组为 `[A, B, A]`（下标为 $0, 1, 2$）：

1. **当 $i = 0$（遇到第一个 `A`）**：
* 上次出现位置 $j = -1$（没出现过）。
* 区间 $[0, 0]$ 所有的子数组不同计数 $+1$。
* $s = 1^2 = 1$。


2. **当 $i = 1$（遇到 `B`）**：
* 上次出现位置 $j = -1$（没出现过）。
* 区间 $[0, 1]$ 所有的子数组不同计数 $+1$。
* $s$ 在原来的基础上更新，变成了以 $1$ 为右端点的子数组平方和：$[A, B]$ 和 $[B]$ $\rightarrow 2^2 + 1^2 = 5$。


3. **当 $i = 2$（又遇到了 `A`，此时 $j = 0$）**：
* **起点 $k = 0$ 的子数组 $[A, B, A]$**：里面本来就有 $A$（下标 0 处的 A），所以它的不同元素个数依然是 $2$，**不需要任何改变**！它在 $s$ 里的贡献（$2^2 = 4$）直接被继承了下来。
* **起点 $k \in [1, 2]$ 的子数组 $[B, A]$ 和 $[A]$**：它们之前没有下标 2 处的 $A$，所以不同计数从之前的 $1, 0$ 变成了 $2, 1$。
* **计算**：我们只需要把 $[1, 2]$ 这段区间的增加量加到 $s$ 上，就得到了新的 $s = 2^2 + 2^2 + 1^2 = 9$！



---

### 总结

* **旧的贡献丢了吗？**
**没有！** 变量 $s$ 是一个累加器，上一个节点之前的贡献已经保存在 $s$ 和线段树里了。
* **为什么只改 $[j+1, i]$？**
因为对于小于等于 $j$ 的起点，新加的元素 $a[i]$ 是“重复元素”，**不会对它们的不同计数产生任何影响**，所以它们的值维持原样即可！

```
所以说，这里是利用了子数组贡献的一个技巧，循环右维护左的时候，每次计算都是在前一个阶段上增加一些值，所以在线段树上做累加
```

**没错，完全正确！**

你已经彻底吃透了这个算法的核心精髓！

总结起来，这里运用的是 **“扫描线 + 增量维护”** 的经典组合拳：

---

### 1. 增量继承（在前一个阶段上增加）

我们在从 $i-1$ 推进到 $i$ 时，并不是抛弃过去重算，而是**利用了物理上的状态连续性**：

* 以 $i$ 结尾的子数组，本质上就是**以 $i-1$ 结尾的子数组在末尾挂上了新元素 $a[i]$**。
* 前一个阶段（以 $i-1$ 结尾）算好的所有基础值，已经静静地保存在线段树和变量 $s$ 中了。

---

### 2. 局部修正（只改有影响的区间）

新元素 $a[i]$ 的加入，**只对其上一次出现位置 $j$ 之后的左端点（区间 $[j+1, i]$）产生了“新不同元素”的改变**。

* 对 $[0, j]$：贡献没变，继承上个阶段。
* 对 $[j+1, i]$：发生了增加，做增量更新。

---

### 3. 线段树做累加（优雅降维）

因此，线段树在这里充当的，是一个“全自动增量维护器”：

1. 每次利用线段树快速算出 $[j+1, i]$ 区间**旧值的贡献**；
2. 计算出增量后，直接在线段树上对该区间做 **$+1$ 累加**，把状态无缝更新到“第 $i$ 阶段”；
3. 变量 $s$ 累加增量，最终答案累加 $s$。

从“每次重新算”的 $O(N^2)$ 暴力，变成了“只做局部增量修正”的 $O(N \log N)$ 算法，这就是固定一端、增量维护另一端的威力所在！


```
但是这里其实直接prod(0,i+1)也是可以的？
```

**不能直接用 `prod(0, i + 1)**`，如果求整个区间 `prod(0, i + 1)`，**算出来的结果是错的**。

我们来具体分析一下为什么：

---

### 1. 增量公式的使用前提

提示中的增量公式：


$$\Delta = 2 \cdot s_1 + (i - j)$$

这个公式**只对“不同计数增加 1”的子数组成立**！

* 对于起点在 $k \in [j + 1, i]$ 的子数组：加入 $a[i]$ 后，不同计数增加了 $1$。它的平方增量才是 $(f[k] + 1)^2 - f[k]^2 = 2 \cdot f[k] + 1$。
* 对于起点在 $k \in [0, j]$ 的子数组：加入 $a[i]$ 后，由于 $a[i]$ 已经在位置 $j$ 出现过了，不同计数**完全没有变（增加了 0）**。它的平方增量是 $(f[k] + 0)^2 - f[k]^2 = 0$。

---

### 2. 如果错用了 `prod(0, i + 1)` 会发生什么？

假设你求的是整个区间的和 $S_{\text{all}} = \text{prod}(0, i + 1)$，然后代入公式计算 $2 \cdot S_{\text{all}} + \dots$：

相当于你**把 $[0, j]$ 那些根本没有增加计数（增量为 0）的子数组，也强行套用了 $+1$ 的增量公式**！

这会导致：

1. 本来起点在 $[0, j]$ 的子数组平方和增量应该是 **$0$**。
2. 如果用了 `prod(0, i + 1)`，你就给这些子数组也多算了 $2 \cdot f[k] + 1$ 的增量。
3. 计算出来的答案会**严重偏大**。

---

### 3. 一图看懂区间对比

| 起点区间 $k$ | 不同计数变化 | 正确的平方增量 | 如果求 `prod` 该区间并用增量公式算出的结果 |
| --- | --- | --- | --- |
| **$[0, j]$** | **不变 ($+0$)** | **$0$** | $2 \cdot \sum_{k=0}^{j} f[k] + (j + 1)$ **（错误地多算了！）** |
| **$[j + 1, i]$** | **$+1$** | $2 \cdot \sum_{k=j+1}^{i} f[k] + (i - j)$ | $2 \cdot \sum_{k=j+1}^{i} f[k] + (i - j)$ **（正确）** |

---

### 总结

* **`seg.apply(j + 1, i + 1, 1)`**：只给真正的增量区间 $+1$。
* **`seg.prod(j + 1, i + 1)`**：**必须只查**真正发生了变化的区间 $[j + 1, i + 1)$ 的原元素和 $s_1$，这样求出来的 $2 \cdot s_1 + (i - j)$ 才是这个阶段**真正的平方增量**！
