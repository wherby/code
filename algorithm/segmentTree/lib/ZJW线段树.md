

**ZKW 线段树**（张昆玮线段树）是由前清华大学 OI 选手张昆玮提出的一种**自底向上（Bottom-up）、非递归**的线段树实现方式。

传统线段树通常基于递归和自顶向下的自左/自右划分（自顶向下，Top-down），代码冗长且含有较大的递归常数开销；而 ZKW 线段树把树形结构直接映射到一个数组中，利用位运算实现自底向上的迭代更新和区间查询。

---

### 一、 核心原理

#### 1. 数组空间与叶节点定位

ZKW 线段树会将底层叶节点扩充到 $2^k$（即大于等于数组长度 $N$ 的最小 2 的幂次 $N'$）。

* **叶节点位置**：原数组下标为 `i` 的元素，直接存放于线段树数组的 `N' + i` 位置。
* **父子关系**：对于节点 `p`，其左儿子为 `p << 1`，右儿子为 `p << 1 | 1`，父节点为 `p >> 1`。

#### 2. 自底向上更新（Single-point Update）

修改 `i` 位置的值时，先直接修改 `p = N' + i`，然后只需一个极简的循环向上更新到根节点：

```python
def update(i, val):
    p = N_prime + i
    tree[p] = val
    p >>= 1
    while p > 0:
        tree[p] = combine(tree[p << 1], tree[p << 1 | 1])
        p >>= 1

```

#### 3. 极速区间查询（Range Query）

查询区间 $[L, R]$ 时，ZKW 线段树将其转换为**开区间** $(L-1, R+1)$，然后利用左右指针双向夹逼：

* 左指针 $x = L - 1 + N'$，右指针 $y = R + 1 + N'$。
* 当 $x$ 是**左儿子**（$x \ \& \ 1 == 0$）时，说明其右兄弟完全在查询范围内，将其右兄弟纳入贡献，并把 $x$ 向右移一位。
* 当 $y$ 是**右儿子**（$y \ \& \ 1 == 1$）时，说明其左兄弟完全在查询范围内，将其左兄弟纳入贡献，并把 $y$ 向左移一位。
* 指向父节点 $x >>= 1, y >>= 1$，重复此过程直至 $x$ 与 $y$ 相遇或交错。

---

### 二、 ZKW 线段树 vs 传统线段树

| 特性 | 传统线段树（Top-down） | ZKW 线段树（Bottom-up） |
| --- | --- | --- |
| **实现方式** | 递归 / 栈 | **纯迭代（非递归）** |
| **代码量** | 较长（包含建树、下发、合并多个子函数） | **极短**（核心逻辑仅 10-15 行） |
| **常数与运行速度** | 较慢（频繁递归调用与分支判断） | **极快**（充分利用缓存与位运算，常数很小） |
| **空间开销** | 需 $4N$ 空间 | 仅需 $2 \times 2^{\lceil \log_2 N \rceil}$ 空间 |
| **区间修改（懒标记）** | 天然支持（`pushdown`） | 支持较复杂，需要额外自顶向下标记下发（标记永久化） |

### 三、 Python 极简标准实现模版

以区间和与单点修改为例：

```python
class ZKW_SegTree:
    def __init__(self, nums: list[int]):
        n = len(nums)
        # 计算大于等于 n 的最小 2 的幂
        self.z = 1
        while self.z < n + 2:  # +2 是为了方便留出开区间的边界节点
            self.z <<= 1
            
        self.tree = [0] * (self.z << 1)
        
        # 1. 填入叶节点数据
        for i in range(n):
            self.tree[self.z + i + 1] = nums[i]  # 偏移1位以便处理1-indexed
            
        # 2. 自底向上建树
        for i in range(self.z - 1, 0, -1):
            self.tree[i] = self.tree[i << 1] + self.tree[i << 1 | 1]

    def update(self, idx: int, val: int):
        """单点更新：将 nums[idx] 修改为 val"""
        p = self.z + idx + 1
        self.tree[p] = val
        p >>= 1
        while p:
            self.tree[p] = self.tree[p << 1] + self.tree[p << 1 | 1]
            p >>= 1

    def query(self, l: int, r: int) -> int:
        """区间求和：查询 [l, r]"""
        res = 0
        x = self.z + l      # 开区间左边界 (l-1)+1
        y = self.z + r + 2  # 开区间右边界 (r+1)+1
        
        while x ^ y ^ 1:   # 当 x 和 y 不是同一结点的左右儿子时
            if ~(x & 1):   # x 是左儿子，包含其右兄弟
                res += self.tree[x ^ 1]
            if y & 1:      # y 是右儿子，包含其左兄弟
                res += self.tree[y ^ 1]
            x >>= 1
            y >>= 1
        return res

```

### 总结

ZKW 线段树凭借**代码精简**和**运行速度快**的优势，在竞赛（OI/ICPC）及高时效要求的算法题中极其受欢迎。不过在面临涉及**区间修改（区间加/区间更新）且非重复贡献的复杂懒标记下传**场景时，传统线段树的逻辑往往更易于维护。
