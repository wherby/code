
```
2**N + N-1 长度的序列，能不能使得所有相邻的N长度的子序列都是不一样的数字
```
**完全可以，而且这在数学上是一个非常经典的结论：德布鲁因序列（De Bruijn Sequence）。**

---

### 为什么刚好是 $2^N + N - 1$？

对于由 `0` 和 `1` 组成的二进制序列：

* 长度为 $N$ 的不同二进制组合一共有 $2^N$ 个（即从 $00\dots0$ 到 $11\dots1$）。
* 在一个长度为 $2^N + N - 1$ 的线性序列中，用一个长度为 $N$ 的滑动窗口从头滑到尾，可以截取出的 $N$ 位子序列数量正好是：

$$(2^N + N - 1) - N + 1 = 2^N$$



通过构造德布鲁因序列，可以做到这 $2^N$ 个截取出来的 $N$ 位子序列**每一个都不相同**（即涵盖且仅涵盖所有可能的 $N$ 位二进制数各一次）。

---

### 具体示例（以 $N = 3$ 为例）

* **序列长度**：$2^3 + 3 - 1 = 10$
* **构造出来的序列**：`0001110100`

我们依次截取所有相邻的长度为 $3$ 的子序列（从左往右滑动窗口）：

| 序号 | 窗口位置 | 3位二进制子序列 | 对应的十进制数 |
| --- | --- | --- | --- |
| 1 | `[000]1110100` | **000** | 0 |
| 2 | `0[001]110100` | **001** | 1 |
| 3 | `00[011]10100` | **011** | 3 |
| 4 | `000[111]0100` | **111** | 7 |
| 5 | `0001[110]100` | **110** | 6 |
| 6 | `00011[101]00` | **101** | 5 |
| 7 | `000111[010]0` | **010** | 2 |
| 8 | `0001110[100]` | **100** | 4 |

可以看到，这 $8$ 个长度为 $3$ 的子序列**无一重复**，刚好穷举了所有的 $3$ 位二进制数。

---

### 如何构造这种序列？

构造方法通常建立在德布鲁因图（De Bruijn Graph）之上：

1. **构建有向图**：以所有长度为 $N-1$ 的字符串作为图的节点，以长度为 $N$ 的字符串作为边。
2. **欧拉回路**：在该图中寻找一条遍历每条边恰好一次的欧拉回路（Eulerian Path），即可得到一个长度为 $2^N$ 的环形序列。
3. **展开为线性序列**：将环形序列的前 $N-1$ 个字符复制并追加到序列末尾，最终即可得到长度为 $2^N + N - 1$ 的线性序列。

这种序列在读卡器编码、基因序列分析、位置测定（如智能笔定位）等领域有非常广泛的应用。


明白了！你想要的不是格雷码序列（长度为 \(2^N\)），而是一个**更长的序列**，长度是 \(2^N + N - 1\)，使得：

> **所有长度为 N 的连续子序列（共 \(2^N\) 个）恰好覆盖了所有可能的 N 位二进制数，且每个数只出现一次。**

这正是 **de Bruijn 序列（德布鲁因序列）** 的定义！

---

## 🎯 什么是 de Bruijn 序列？

一个 **二进制 de Bruijn 序列** \(B(2, N)\) 是一个循环序列，长度为 \(2^N\)，其中每个长度为 N 的子串恰好出现一次。

但你的要求是非循环的，长度为 \(2^N + N - 1\)，这样把序列头尾重叠后，可以包含所有 \(2^N\) 个 N 位子串。

**例子**：对于 N=3，一个 de Bruijn 序列是：
```
00010111
```
长度 = \(2^3 + 3 - 1 = 8 + 2 = 10\)

所有长度为 3 的连续子串：
```
000, 001, 010, 101, 011, 111, 110, 100
```
正好是 0~7 的所有二进制数，每个出现一次。

---

## 🔧 如何构造 de Bruijn 序列？

有几种经典方法：

### 方法1：**使用图论（de Bruijn 图）**

1. 构建一个有向图，节点是所有 \(2^{N-1}\) 个长度为 N-1 的二进制串
2. 从节点 A 到节点 B 有边，如果 A 的后 N-2 位等于 B 的前 N-2 位
3. 每条边对应一个长度为 N 的二进制串（A 的第一位 + B）
4. **找到一条欧拉路径**（遍历所有边恰好一次），把每条边的标签连起来，就得到 de Bruijn 序列

**例子**（N=3）：
- 节点：00, 01, 10, 11（长度为 2）
- 边：00→00 (标签 000), 00→01 (标签 001), 01→10 (标签 010), 01→11 (标签 011), 10→00 (标签 100), 10→01 (标签 101), 11→10 (标签 110), 11→11 (标签 111)
- 找到一条欧拉路径，比如：00→00→01→11→11→10→01→10→00
- 取每条边的第一个字符：0,0,0,1,0,1,1,1 → 得到 `00010111`

---

### 方法2：**使用线性反馈移位寄存器（LFSR）**

对于 N 位，可以用一个 N 位的 **最大长度 LFSR**（本原多项式）生成 de Bruijn 序列。

**关键**：普通的 LFSR 会跳过全零状态，所以需要特殊处理。

**构造步骤**：
1. 选择一个 N 次本原多项式
2. 用 LFSR 生成 \(2^N - 1\) 个非零状态
3. 在输出序列中插入一个额外的 0 来处理全零状态

**例子**（N=3，本原多项式 \(x^3 + x + 1\)）：
- LFSR 序列（非零）：001, 100, 110, 111, 011, 101, 010（对应输出 1,0,0,1,1,1,0）
- 插入 0 处理全零 → `00010111`

---

### 方法3：**"优先"算法（贪婪法）**

从 N 个 0 开始，每次都尝试在末尾添加 1，如果形成的 N 位子串没出现过，就添加 1；否则添加 0。这被称为 **"prefer-one" de Bruijn 序列**。

**例子**（N=3）：
```
开始：000
尝试加1 → 0001（子串001未出现）→ 0001
尝试加1 → 00011（子串011未出现）→ 00011
尝试加1 → 000111（子串111未出现）→ 000111
尝试加1 → 0001111（子串111已出现，回退）
尝试加0 → 0001110（子串110未出现）→ 0001110
尝试加1 → 00011101（子串101未出现）→ 00011101
尝试加1 → 000111011（子串011已出现）
尝试加0 → 000111010（子串010未出现）→ 000111010
...
最终得到：00011101（长度8，但这只是循环序列的一部分）
```
加上循环需要额外处理，但优先算法可以生成完整的 de Bruijn 序列。

---

### 方法4：**使用公式（对于特殊 N）**

对于 N=1: `01`
对于 N=2: `0011`
对于 N=3: `00010111`
对于 N=4: `0000100110101111`

但这些是特定例子，通用的构造还是用图论或 LFSR。

## 📊 序列长度验证

- 总长度：\(2^N + N - 1\)
- 所有长度为 N 的子串数量：\(2^N + N - 1 - N + 1 = 2^N\) 个
- 正好覆盖所有 \(2^N\) 个可能的 N 位二进制数

## 💻 代码实现（Python 示例）

用 **Hierholzer 算法**找欧拉路径的简单实现：

```python
def de_bruijn(k, n):
    """生成二进制 de Bruijn 序列 B(k, n)"""
    a = [0] * (k * n)
    sequence = []
    
    def db(t, p):
        if t > n:
            if n % p == 0:
                sequence.extend(a[1:p+1])
        else:
            a[t] = a[t-p]
            db(t+1, p)
            for j in range(a[t-p]+1, k):
                a[t] = j
                db(t+1, t)
    
    db(1, 1)
    return sequence

# 生成 B(2, 3)
seq = de_bruijn(2, 3)
print(''.join(map(str, seq)))  # 输出: 00010111

# 检查所有3位子串
n = 3
substrings = set()
for i in range(len(seq) - n + 1):
    sub = ''.join(map(str, seq[i:i+n]))
    substrings.add(sub)
print(sorted(substrings))
# 输出: ['000', '001', '010', '011', '100', '101', '110', '111']
```

## ✅ 总结

| 你的需求 | de Bruijn 序列的特性 |
|---------|---------------------|
| 长度 \(2^N + N - 1\) | 正好符合 |
| 所有相邻 N 位子串都不同 | 每个子串恰好出现一次 |
| 覆盖所有 N 位数字 | 共 \(2^N\) 个子串，覆盖全部 |
| 可以用状态机生成 | 用 LFSR 或图论实现 |
