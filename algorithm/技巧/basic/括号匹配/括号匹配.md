
https://leetcode.cn/problems/valid-parenthesis-string/description/?envType=daily-question&envId=2026-10-04
给你一个只包含三种字符的字符串，支持的字符类型分别是 '('、')' 和 '*'。请你检验这个字符串是否为有效字符串，如果是 有效 字符串返回 true 。

有效 字符串符合如下规则：

任何左括号 '(' 必须有相应的右括号 ')'。
任何右括号 ')' 必须有相应的左括号 '(' 。
左括号 '(' 必须在对应的右括号之前 ')'。
'*' 可以被视为单个右括号 ')' ，或单个左括号 '(' ，或一个空字符串 ""。

这里如果使用状态表示法
```python 
class Solution:
    def checkValidString(self, s: str) -> bool:
        vod = 0 
        cur = 0
        for a in s:
            if a =="(":
                cur +=1
            elif a == ")":
                if cur ==0 and vod ==0:
                    return False 
                if cur ==0:
                    vod -=1
                else:
                    cur -=1 
            else:
                vod +=1
        return cur <=vod
```
这时候遇上 "*(()" 则会返回错误的结果，这里明显不能匹配成功

这时就需要上下限表示法计算
```python 
class Solution:
    def checkValidString(self, s: str) -> bool:
        hi=lo = 0 
        for a in s:
            if a =="(":
                hi +=1
                lo +=1
            elif a ==")":
                hi -=1
                lo -=1
                if hi <0:
                    return False 
            else:
                hi +=1
                lo -=1
            if lo <0:
                lo =0 
        return lo ==0
```

对于状态表示法，使用双向验证则可以：
```python
class Solution:
    def checkValidString(self, s: str) -> bool:
        def verify(s):
            vod = 0 
            cur = 0
            for a in s:
                if a =="(":
                    cur +=1
                elif a == ")":
                    if cur ==0 and vod ==0:
                        return False 
                    if cur ==0:
                        vod -=1
                    else:
                        cur -=1 
                else:
                    vod +=1
            return cur <=vod
        sr = list(s[::-1])
        for i,a in enumerate(sr):
            if a =="(":
                sr[i] = ")"
            if a ==")":
                sr[i] = "("
        return verify(s) and verify(sr)
```
