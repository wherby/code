这个提示给出的“固定右端点 + 单调栈维护平台状态”的思路极其精妙！它将原问题从 $O(n \log n)$ 的分治/笛卡尔树复杂度，直接优化到了 **$O(n)$ 时间复杂度和 $O(n)$ 空间复杂度**，是该问题的最优解法。

我们可以把这个过程拆解得更清晰一些，看看单调栈究竟在维护什么，以及为什么奇偶性可以高效转移。

---

### 核心机制拆解

假设当前遍历到右端点 $r$（数值为 $v = a[r]$）。

对于固定的右端点 $r$，当左端点 $l$ 从 $r$ 一直向左退到 $1$ 时：

* 子数组 $a[l..r]$ 的最小值 $\min(a[l..r])$ 是**单调不减**的。
* 连续相同的最小值会形成一个个“平台（Platform）”。

单调栈中的每个元素，就代表这样一个**最小值相同的左端点区间（平台）** $[L_{seg}, R_{seg}]$。

#### 1. 单调栈节点需要维护什么信息？

对于栈中的某一段平台（其代表的最小值统一为 $val$）：

* `val`: 该平台的最小值。
* `L`, `R`: 该平台对应的左端点范围 $[L, R]$。
* `cnt[0]`: 在这个平台范围内的左端点 $l \in [L, R]$ 中，子数组 $a[l..r]$ 的最小值 $val$ 出现了**偶数次**的左端点个数。
* `cnt[1]`: 子数组 $a[l..r]$ 的最小值 $val$ 出现了**奇数次**的左端点个数。

同时，我们用全局变量 `total_odd_count` 实时维护**当前栈中所有平台中 `cnt[1]` 的总和**。每轮遍历 $r$，只需要把 `total_odd_count` 累加进最终答案即可！

---

### 状态转移与栈的操作逻辑

当加入新元素 $a[r]$ 时，我们不断弹出栈顶比 $a[r]$ **严格更大**的元素：

#### 步骤 1：Pop 弹出被覆盖的平台（`st.top().val > a[r]`）

* 如果栈顶平台的最小值大于 $a[r]$，说明以 $a[r]$ 为右端点时，原先这些平台的最小值全部被更新成了更小的 $a[r]$。
* **操作**：将弹出平台的 `cnt[1]` 从全局 `total_odd_count` 中扣除。
* **吞并**：这个弹出的区间 $[L, R]$ 被新元素 $a[r]$ 吸收（因为它们的最小值都变成了 $a[r]$）。

#### 步骤 2：处理相同的最小值（`st.top().val == a[r]`）

如果在 Pop 完之后，栈顶元素的最小值**正好等于** $a[r]$：

* 说明 $a[r]$ 的加入，让原先在这个平台里的所有子数组，其最小值的出现次数都**增加了 1**。
* **奇偶互换**：原先出现了偶数次的（`cnt[0]`），现在变成了奇数次（`cnt[1]`）；原先奇数次的变成了偶数次。
* **更新全局**：先从 `total_odd_count` 中减去旧的 `cnt[1]`，然后交换该平台的 `cnt[0]` 和 `cnt[1]`，再将新的 `cnt[1]` 加回 `total_odd_count`。
* **合并**：将新吸收的所有区间与这个栈顶平台合并。同时，$l = r$ 这个新的左端点（只包含 $a[r]$ 自己，最小值 $a[r]$ 出现了 1 次，即奇数次）也合并进来，即该平台的 `cnt[1]` 额外 $+1$。

#### 步骤 3：处理更小或栈空的情况（`st.top().val < a[r]` 或 栈空）

如果 Pop 完后栈空，或者栈顶的最小值小于 $a[r]$：

* 说明所有被吸收的区间 $[L, r]$（包括 $l=r$ 自己）它们的最小值都是 $a[r]$，且 $a[r]$ 在这些子数组中**只出现了 1 次**（奇数次）。
* **新建平台**：将合并后的区间作为一个新节点压入栈中，其 `cnt[1] = 区间长度`，`cnt[0] = 0`。
* **更新全局**：将该新节点的 `cnt[1]` 加到 `total_odd_count` 中。

### 复杂度分析

* **时间复杂度**：$O(n)$。每个位置作为平台端点最多入栈 1 次、出栈 1 次，所有栈操作均摊为 $O(1)$。
* **空间复杂度**：$O(n)$。单调栈最多存储 $n$ 个元素。

这个“固定右端点 + 状态翻转”的单调栈技巧在处理**子数组频次奇偶性/模数**问题上非常优雅且高效！

### 代码的核心变量与逻辑解析

栈中元组存入的数据为：`(val, idx, dp1, dp2)`

* **`val`**：当前平台的最小值。
* **`idx`**：该平台**上一次出现** `val` 的数组下标（如果只出现了一次，就是当前下标 $i$）。
* **`dp1`**：以当前 $i$ 为右端点时，该平台中最小值 `val` 出现**奇数次**的左端点数量。
* **`dp2`**：以当前 $i$ 为右端点时，该平台中最小值 `val` 出现**偶数次**的左端点数量。
* **`cur`**：当前以 $i$ 为右端点时，**整个数组中**满足条件的左端点总数（即栈中所有平台的 `dp1` 之和）。

#### 状态转移的三个分支：

1. **Pop 弹出过程（`stk[-1][0] > nums[i]`）**：
* 当遇到更小的值 `nums[i]` 时，栈顶元素被弹除，这些区间被 `nums[i]` 吸收。
* 扣除对应的奇数计数：`cur -= stk[-1][2]`（即扣除被弹出平台的 `dp1`）。


2. **新建平台（`stk[-1][0] != nums[i]`）**：
* 此时 `nums[i]` 比栈顶元素严格更大，成为一个新的平台。
* 覆盖的左端点区间长度为 `i - stk[-1][1]`（包含吸收掉的更低平台区间）。
* 因为 `nums[i]` 是第一次出现在这个区间，所以这 $i - stk[-1][1]$ 个左端点对应的 `nums[i]` 出现次数都是 $1$（奇数次）。
* 新节点为 `(nums[i], i, i - stk[-1][1], 0)`。


3. **合并平台与奇偶翻转（`stk[-1][0] == nums[i]`）**：
* 栈顶元素的最小值与 `nums[i]` 相同。
* 弹出旧状态 `(val, idx, dp1, dp2)`，先扣除旧的奇数贡献 `cur -= dp1`。
* **状态更新**：
* 新的 `dp1`（奇数次）来自两部分：
1. **之前的偶数次变奇数次**：原本有 `dp2` 个左端点，再加入当前 `nums[i]` 后出现次数加 1，变为奇数次。
2. **新增的中间区间与自己**：从上一次出现位置 `idx` 之后到当前 $i$ 的区间（即 $l \in (idx, i]$），`nums[i]` 在这些子数组中只出现了 $1$ 次（奇数次），长度为 `i - idx`。


* 组合起来：**新的 `dp1 = dp2 + i - idx**`。


* 新的 `dp2`（偶数次）：原本出现奇数次（`dp1`）的左端点，再加入当前 `nums[i]` 后变成偶数次，即 **新的 `dp2 = dp1**`。


* 将更新后的状态 `(nums[i], i, dp2 + i - idx, dp1)` 压回栈中。

### 完整可运行代码

补充标准 Competitive Programming 快速输入模板后的完整 Python 代码：

```python
import sys

# 快速输入模板
input = sys.stdin.read

def II():
    return int(sys.stdin.readline())

def LII():
    return list(map(int, sys.stdin.readline().split()))

def solve():
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    iterator = iter(input_data)
    t = int(next(iterator))
    outs = []
    
    inf = float('inf')
    
    for _ in range(t):
        n = int(next(iterator))
        nums = [int(next(iterator)) for _ in range(n)]
        
        ans = 0
        cur = 0
        
        # 哨兵 (-inf, -1, 0, 0) 避免边界判断
        stk = [(-inf, -1, 0, 0)]
        
        for i in range(n):
            # 1. 弹出被 nums[i] 覆盖的大值平台
            while stk[-1][0] > nums[i]:
                cur -= stk[-1][2] # 扣除 dp1
                stk.pop()
            
            # 2. 新建平台
            if stk[-1][0] != nums[i]:
                stk.append((nums[i], i, i - stk[-1][1], 0))
            # 3. 平台合并，奇偶状态翻转
            else:
                val, idx, dp1, dp2 = stk.pop()
                cur -= dp1
                stk.append((nums[i], i, dp2 + i - idx, dp1))
            
            # 累加当前平台的奇数贡献并计入总答案
            cur += stk[-1][2]
            ans += cur
        
        outs.append(ans)
    
    print('\n'.join(map(str, outs)))

if __name__ == '__main__':
    solve()

```

### 算法表现

* **时间复杂度**：$\mathcal{O}(n)$。每个元素入栈/出栈至多一次，非常适合数据量 $n \ge 10^5$ 的在线编程竞赛题目。
* **空间复杂度**：$\mathcal{O}(n)$。主要是单调栈占用的空间。
