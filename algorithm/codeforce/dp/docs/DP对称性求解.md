这道题中的“对称”并不是物理上“往左跳和往右跳消耗相同”的对称，而是**博弈/决策结构上的“镜像对称”**：

---

### 1. 结构上的镜像对称

对于任意一个长度为 $i$ 的候选区间，无论它位于 Galactic 直线的什么位置：

* **在左端点向右搜寻：**
如果你向右跳跃 $j$ 的距离（把区间切成长度为 $j$ 和 $i - j$ 的两段）：
* 若目标在**左侧**（长度 $j$ 的这段），你降落的位置恰好是这 $j$ 个星球的**右端点**，下一步转化为了在长度 $j$ 的区间内**从右端点开始搜寻**（即 $DP_R[j]$）。
* 若目标在**右侧**（长度 $i - j$ 的这段），你降落的位置恰好是这 $i - j$ 个星球的**左端点**，下一步转化为了在长度 $i - j$ 的区间内**从左端点开始搜寻**（即 $DP_L[i - j]$）。


最坏情况下的后续代价就是：

$$\text{worst\_case} = \max(DP_R[j], \, DP_L[i - j])$$


* **在右端点向左搜寻：**
如果你向左跳跃 $i - j$ 的距离（同样把区间切成长度为 $j$ 和 $i - j$ 的两段）：
* 若目标在**右侧**（长度 $j$ 的这段），你降落的位置恰好是这 $j$ 个星球的**左端点**（$DP_L[j]$）。
* 若目标在**左侧**（长度 $i - j$ 的这段），你降落的位置恰好是这 $i - j$ 个星球的**右端点**（$DP_R[i - j]$）。


最坏情况下的后续代价**完全是一模一样的表达式**：

$$\text{worst\_case} = \max(DP_R[i - j], \, DP_L[j]) = \max(DP_R[j], \, DP_L[i - j])$$



---

### 2. 为什么这样可以把状态简化到 $O(N)$？

正因为**切分出来的子问题结构在左右端点之间形成了完美的交叉/镜像对应**（$DP_L$ 的结果依赖 $DP_R$ 和 $DP_L$，反之亦然），所以：

1. **子问题的决策风险是固定的**：决定后续“最坏情况”的 `v = max(dp_r[j], dp_l[i - j])` 对左端点决策和右端点决策是完全相同的。
2. **唯一不同的是“当下的位移开销”**：
* 在左端点，你消耗的是**正向位移 $j$ 的开销** `dis[n + j]`；
* 在右端点，你消耗的是**反向位移 $i - j$ 的开销** `dis[n - (i - j)]`。



因此，我们不需要关心区间具体在 $1 \sim N$ 的什么位置（$O(N^2)$ 个区间），只需要记录：

* `dp_l[i]`：长度为 $i$ 时从**左**端点出发的最小最大代价
* `dp_r[i]`：长度为 $i$ 时从**右**端点出发的最小最大代价

状态数成功被压缩到了 $O(N)$，配合 $O(N)$ 的转移枚举和 $O(N^2)$ 的最短路预处理，整道题就在 $O(N^2)$ 时间内被完美解决了！

你说得完全正确！这里的 `dp_l[i]` 和 `dp_r[i]` **绝对不能拆开各自独立计算，必须在同一个 `i` 的循环中同时交织计算**。

它们之所以交织在一起，本质原因如下：

### 1. 状态转移中的“跨数组依赖”

我们来看转移方程中 `v` 的定义：


$$v = \max(dp\_r[j], \, dp\_l[i - j])$$

注意这里的依赖关系：

* 计算 **`dp_l[i]`**（左端点）时，需要用到 **`dp_r[j]`**（右端点）和 `dp_l[i - j]`；
* 计算 **`dp_r[i]`**（右端点）时，需要用到 **`dp_l[j]`**（左端点）和 `dp_r[i - j]`。

如果尝试“先算完所有的 `dp_l`，再去算 `dp_r`”，你在算 `dp_l[i]` 的时候就会发现需要用到尚未计算出来的 `dp_r[j]`（比如当 $j = i-1$ 时，你需要 `dp_r[i-1]`），计算就会直接陷入死锁。

---

### 2. 区间 DP 的拓扑序（按区间长度 $i$ 递推）

在区间 DP 中，求解的拓扑顺序是**区间的长度 $i$**（从小到大 $2 \to n$）。

当我们在计算长度为 $i$ 的状态时：

* 所有的**较小长度** $1, 2, \dots, i-1$ 的状态（包括 `dp_l[1...i-1]` 和 `dp_r[1...i-1]`）都已经完全计算完毕。
* 由于 $j < i$ 且 $i - j < i$，因此 `dp_r[j]`、`dp_l[j]`、`dp_r[i-j]`、`dp_l[i-j]` 全部都是**已知量**。

所以在同一个 $i$ 下：

1. 先利用已知的前 $i-1$ 项算出 `v = max(dp_r[j], dp_l[i - j])`；
2. 再同时更新 `dp_l[i]` 和 `dp_r[i]`。

---

### 3. 直观理解这种“交织”

* **左端点的命运依赖于右端点**：当你在左端点向右跳跃到一个中间星球 $X$ 时，如果反馈告诉你“目标在 $X$ 的左边”，此时你人停在 $X$（即新子区间的**右端点**），接下来的最优决策成本自然就是 $dp\_r[j]$。
* **右端点的命运依赖于左端点**：同理，当你在右端点向左跳跃到 $X$，如果目标在 $X$ 的右边，你人停在 $X$（新子区间的**左端点**），接下来的最优决策成本就是 $dp\_l[j]$。

正因为“向左跳之后落点变成左端点/右端点”**与**“向右跳之后落点变成右端点/左端点”**是相互转换的，这两个状态才必须像双螺旋结构一样，随着区间长度 $i$ 的增加**同步、交织地向下递推。
