### 1. 关于贪心顺序的精准修正：不是“获取电量最多”，而是“按门槛升序”

你的描述中提到：*“能获取电量最多的放置在最前面，然后消耗中启动需要少的放置在后面”*。

这里需要区分“赚钱（收益 $\ge 0$）子树”**与**“亏钱（收益 $< 0$）子树”两类情况的真实排序依据：

* **对于赚钱的子树（`ws[i] <= 0`，即净收益 $\ge 0$）：**
* **排序依据：** 应该按**起步门槛（`v0[i]`）从小到大（升序）** 排在最前面，**而不是按获取电量多少**。
* **原因：** 只要是赚钱的子树，做完都能回血。我们应该**优先做起步门槛最低的**，先用最少的初始电量把第一块“甜头”拿到手，赚到电量后再去挑战门槛更高的赚电子树。


* **对于亏钱的子树（`ws[i] > 0`，即净收益 $< 0$）：**
* **排序依据：** 应该按`ws[i] - v0[i]` 升序（相当于按“末尾剩余电量要求”降序）排在后面。
* **原因：** 亏钱子树做完电量就会减少，越往后越危险。按这个关键字排序可以保证在连续亏电的过程中，所需电量的峰值最高点被降到最低。



> **小结：** 总体顺序是 **【赚钱子树（按门槛升序）】 $\to$ 【亏钱子树（按末尾剩余需求降序）】**。

### 2. 关于“留下哪棵子树”：枚举终结子树并做三阶段安全校验

这里的完整流程是：

1. 我们预先按照上述贪心规则将所有子树排成一个固定序列 $S$；
2. **枚举**序列中的每一棵子树 $i$ 作为“最终留在里面、不返回 $u$”的终结子树；
3. 对于确定的子树 $i$，剩余子树的相对顺序保持不变（分为**前缀子树**与**后缀子树**）；
4. 通过 **`max(前缀安全线, 后缀安全线, 终点安全线)`** 计算出以 $i$ 终结时 $u$ 点所需的初始电量；
5. 在所有子树 $i$ 的枚举结果中**取最小值 (`fmin`)**，即为 `dp1[u]`。

代码中对消耗量定义为 $ws[x]$（正数表示亏电，负数表示赚电），$v0[x]$ 表示门槛。

对于亏电的子树（$ws[x] > 0$），我们要对其进行排序。
假设有相邻的两个亏电子树 $i$ 和 $j$：

* **方案 A（先 $i$ 后 $j$）：** 要求的门槛为 $\max(v0[i], ws[i] + v0[j])$
* **方案 B（先 $j$ 后 $i$）：** 要求的门槛为 $\max(v0[j], ws[j] + v0[i])$

要让 **方案 A < 方案 B**，即：


$$\max(v0[i], ws[i] + v0[j]) < \max(v0[j], ws[j] + v0[i])$$

由于 $ws[i] > 0, ws[j] > 0$，交叉项 $ws[i] + v0[j]$ 和 $ws[j] + v0[i]$ 必然占据主导。式子简化为：


$$ws[i] + v0[j] < ws[j] + v0[i] \iff ws[i] - v0[i] < ws[j] - v0[j]$$

因此，按 `ws[x] - v0[x]` 进行**升序排序**（较小的排前面），**完全符合最优贪心顺序**！

### 一、 为什么要分为“前缀子树 $\rightarrow$ 后缀子树 $\rightarrow$ 最终进入 $i$”？

假设当前节点 $u$ 有 4 个子树，按我们的贪心规则（赚电量的排前面，亏电量的排后面）排好序后，序列为：

$$\text{排序好的子树序列 } S = [A, B, C, D]$$

如果 Henry 决定**在子树 $C$ 内部某处终结**（即 $C$ 是第 $i$ 个子树），这意味着什么？

1. **子树 $C$ 只能走单程：** Henry 跨过边进入子树 $C$ 后，就在 $C$ 内部激活 Portal 离开了，**再也不会返回节点 $u$**。
2. **其他子树（$A, B, D$）必须走双程：** 因为 Henry 必须访问树上的每一个节点，所以除了最终终结的子树 $C$ 之外，**所有其他子树都必须完整遍历并返回 $u$**。

那其他子树 $A, B, D$ 应该按什么顺序遍历呢？
为了让电量门槛尽可能低，除了被选为终结的 $C$ 以外，**剩余子树之间依然要严格保持原本最优的相对顺序**：

* 在 $C$ 前面的子树（前缀 $A, B$）：按原顺序遍历并返回；
* 在 $C$ 后面的子树（后缀 $D$）：在遍历完前缀后，**接着按原顺序遍历并返回**；
* **最后**：跨过单程边进入 $C$，并在 $C$ 内部终结。

所以，实际的遍历路线为：


$$\text{节点 } u \longrightarrow \underbrace{A \to B}_{\text{前缀子树 (Pre)}} \longrightarrow \underbrace{D}_{\text{后缀子树 (Suf)}} \longrightarrow \underbrace{\text{进入 } C \text{ 并在内部终结}}_{\text{终结子树 } (i)}$$

---

### 二、 三阶段门槛的物理含义

为了保证 Henry 在上面整条路线中**任何时刻电量都不降为负数**，我们必须算出这三个阶段分别对“在 $u$ 点起步时的初始电量”提出的最高要求：

```
[起始点 u] ---> (阶段 1: 遍历前缀 A,B) ---> (阶段 2: 遍历后缀 D) ---> (阶段 3: 进入 C 终结)

```

1. **阶段 1（前缀门槛：`dp0[u]`）**
* 在遍历前缀子树 $A, B$ 的过程中，需要满足它们的起步门槛。
* `dp0[u]` 在循环走到 $C$ 的这一轮时，正好记录了**处理完前缀 $A, B$ 所需的峰值门槛**。


2. **阶段 2（后缀门槛：`suff[idx + 1] + cur_w`）**
* 遍历完前缀 $A, B$ 后，Henry 身上已经**净消耗**了 `cur_w` 的电量。
* 接下来要处理后缀子树 $D$，后缀子树 $D$ 本身需要的起步门槛是 `suff[idx + 1]`。
* 折算回刚在 $u$ 点出发的时候，初始电量必须达到：`suff[idx + 1] + cur_w`。


3. **阶段 3（终结子树门槛：`tot[u] - ws[C] + v1[C]`）**
* 当前缀 $A, B$ 和后缀 $D$ 都遍历完后，Henry 准备进入 $C$。
* 此时除 $C$ 以外所有子树的总消耗为：`tot[u] - ws[C]`（即全部子树消耗减去 $C$ 的消耗）。
* 进入子树 $C$ 并在内部终结需要的门槛是 $v1[C]$。
* 折算回刚在 $u$ 点出发的时候，初始电量必须达到：`tot[u] - ws[C] + v1[C]`。
