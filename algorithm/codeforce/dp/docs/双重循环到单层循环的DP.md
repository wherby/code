### 1. 函数视角的推导

固定前缀右端点 $r_1 = i$ 时，对于其右侧任意一个固定的后缀起点 $l_2$（满足 $l_2 > i$），它所能提供的总贡献可以写成关于 $l_2$ 的函数：

$$g_i(l_2) = \underbrace{v_2[l_2] \cdot y}_{\text{后缀价值 } L_2} + \underbrace{(l_2 - i - 1) \cdot z}_{\text{间隔价值 } G}$$

我们将 $i$ 项展开拆分：


$$g_i(l_2) = \Big( v_2[l_2] \cdot y + l_2 \cdot z - z \Big) - i \cdot z$$

注意到，括号内的部分 **完全独立于 $r_1$（即独立于 $i$）**！
我们定义一个只与 $l_2$ 有关的固定基准函数 $H(l_2)$：


$$H(l_2) = v_2[l_2] \cdot y + (l_2 - 1) \cdot z$$

那么对于任意的 $i$，任意 $l_2$ 的贡献都可以表达为：


$$g_i(l_2) = H(l_2) - i \cdot z$$

---

### 2. 为什么从右往左遍历时取到的就是最佳值？

当前缀右端点从 $i+1$ 变为 $i$ 时（向左移动 1 位）：

1. **相对顺序不变**：
对于右侧已有的任意两个后缀起点 $l_2^{(1)}$ 和 $l_2^{(2)}$：

$$g_i(l_2^{(1)}) - g_i(l_2^{(2)}) = H(l_2^{(1)}) - H(l_2^{(2)})$$



这个差值与 $i$ 无关！这意味着，**在右侧所有可用的 $l_2$ 中，谁的 $H(l_2)$ 更大，谁就永远更优**，它们之间的优劣顺序不会随着 $r_1$ 的左移而改变。
2. **全局整体偏移（$+z$ 的本质）**：
从 $i+1$ 变到 $i$，所有已存在点 $l_2$ 的函数值都均匀地增加了 $z$：

$$g_i(l_2) = g_{i+1}(l_2) + z$$



这就是代码中 `cur += z` 的数学本质——它不是在重新计算所有 $l_2$，而是把上一轮的历史最大值 $H_{\max}$ **整体平移向上抬升了 $z$**。
3. **新候选点的加入**：
从右往左移动到 $i$ 时，原本不可用的位置 $l_2 = i + 1$ 正式解锁，进入可选集合。
此时只需要将“抬升后的历史最佳值”与“新解锁点 $l_2 = i+1$ 的初始值 $y \cdot v_2[i+1]$”进行一次 $O(1)$ 的比较：

$$\text{cur}_i = \max\Big( \text{cur}_{i+1} + z,\; y \cdot v_2[i+1] \Big)$$



---

### 总结

你说的非常对：**从右往左遍历的过程，本质上就是动态维护候选集合中 $H(l_2)$ 的前缀最大值（Prefix Maximum）。**

由于每次向左移动对所有旧点产生的变化是**均匀且单调增/减的（恒定 $+z$）**，旧点之间的相对大小保持不变，所以我们**根本不需要去维护 $n$ 种可能的 $l_2$**，只需要用一个变量 `cur` 记住历史最优解并不断向左“滚屏”即可！

为了彻底看懂这段代码，我们需要从 **公式转化、状态定义、转移顺序** 三个层次来拆解它的数学与算法逻辑。

---

### 一、 公式转化与变量映射

题目要求的函数表达式：


$$F(l_1,r_1,l_2,r_2) = (r_1-l_1)x + (r_2-l_2)y + (l_2-r_1)z + x + y - z$$

我们将其按“块”重新组合：


$$F = \underbrace{(r_1 - l_1 + 1)}_{A} \cdot x \;+\; \underbrace{(r_2 - l_2 + 1)}_{B} \cdot y \;+\; \underbrace{(l_2 - r_1 - 1)}_{G} \cdot z$$

* **$A$**：前缀段 $S[l_1 \dots r_1]$ 的长度（$A \ge 1$），单位价值为 $x$。
* **$B$**：后缀段 $S[l_2 \dots r_2]$ 的长度（$B \ge 1$），单位价值为 $y$。
* **$G$**：中间间隔 $S[r_1 + 1 \dots l_2 - 1]$ 的长度（$G \ge 0$），单位价值为 $z$。

---

### 二、 核心算法逻辑：从双重循环到单层 DP

如果暴力求解，我们需要枚举前缀右端点 $r_1$ 和后缀左端点 $l_2$（满足 $r_1 < l_2$），复杂度是 $O(n^2)$。

代码的核心思想是：**倒序枚举前缀右端点 $r_1 = i$，用一个动态规划变量 `cur` 实时维护其右侧所有合法 $l_2$ 产生的“最佳后缀 + 间隔”的总贡献。**

#### 1. 变量 `cur` 的物理意义

`cur` 表示：**对于当前的 $r_1 = i$，在其右侧（即 $l_2 > i$）的所有可选位置中，后缀段贡献与中间间隔 $z$ 贡献之和的最大值**。

即：


$$\text{cur} = \max_{l_2 > i} \Big( B(l_2) \cdot y + (l_2 - i - 1) \cdot z \Big)$$

#### 2. 倒序循环中 `cur` 的状态转移（三步精炼逻辑）

在代码的循环中：

```python
for i in range(n - 2, -1, -1):
    cur += z                             # ① 状态继承与拉远
    if v2[i + 1] > 0:
        cur = fmax(cur, y * v2[i + 1])   # ② 纳入新候选点
    if v1[i] > 0:
        ans = fmax(ans, cur + x * v1[i]) # ③ 结合当前前缀更新全局答案

```

这三行代码的顺序逻辑非常严密：

* **第一步：`cur += z**`
当 $r_1$ 从 $i + 1$ 变为 $i$ 时（向左移动 1 位），原本在右侧的所有 $l_2$ 到新 $r_1$ 的距离都**增加了 1**。
因此，之前所有后缀方案的间隔长度 $G$ 都加了 1，整体收益增加 $z$。
*(注：如果之前 `cur` 为 $-\infty$，在 Python 中 $-\infty + z$ 依然为 $-\infty$，不会引发误算)*。
* **第二步：`if v2[i + 1] > 0: cur = fmax(cur, y * v2[i + 1])**`
$r_1 = i$ 时，解锁了一个**全新的**紧邻后缀起点 $l_2 = i + 1$。
此时它的间隔 $G = (i + 1) - i - 1 = 0$。
如果位置 $i + 1$ 可以作为有效后缀的起点（即 `v2[i + 1] > 0`），它的贡献就是 `y * v2[i + 1]`。
`cur` 在“之前被拉远的所有旧方案”与“全新的零间隔方案”之间取最大值。
* **第三步：`if v1[i] > 0: ans = fmax(ans, cur + x * v1[i])**`
如果当前位置 $i$ 可以作为有效前缀的终点（`v1[i] > 0`），并且右侧存在有效的后缀方案（`cur` 已经被更新过、不再是 $-\infty$），那么当前位置的前缀收益 `x * v1[i]` 加上右侧的最佳综合收益 `cur`，就构成了一个完整的合法方案，用来更新全局最大值 `ans`。

---

### 三、 为什么 KMP 数组（`v1` 和 `v2`）可以直接取最长？

* `v1[i]` 是以 $i$ 结尾的最长前缀匹配长度。
* `v2[j]` 是以 $j$ 开头的最长后缀匹配长度。

**为什么不需要考虑更短的 Border 长度？**
因为当 $r_1 = i$ 和 $l_2$ 固定时，中间间隔 $G$ 已经完全固定。
对于固定的 $r_1$，想要 $A \cdot x$ 最大：

1. 若 $x > 0$，必定选最大的 $A$（即 `v1[i]`）。
2. 若 $x \le 0$，理论上选最小的 $A = 1$。但因为我们是枚举每一个位置作为 $r_1$，**更小的长度已经被更左边的 $r_1'$ 遍历到了**。

同理，后缀段 $B \cdot y$ 也只需要在起点固定时取最长的 `v2[i + 1]` 即可。

---

### 总结

这段代码通过 **倒序扫描 + 增量 DP**，巧妙利用了以下性质：

1. 将双重循环的间隔累加转化为简单的 `cur += z`。
2. 利用 Python 处理 `-inf` 的特性，免去了繁琐的状态初始化判断。
3. 利用 KMP 数组 $O(1)$ 查找端点最值，在 **$O(n)$ 时间和 $O(n)$ 空间** 内完美解决了问题。
