这里的本质就是要把好多个分段折线函数（线性的山峰/阶梯形状）累加在一起。

因为有多个不同的 $v$，每一个 $v$ 都会在数组上砸出一条“三段式的折线”。如果把这些折线硬生生叠加在一起，数组的每个位置就会形成一个由各种斜率交织起来的复杂曲线。

### 为什么需要两个差分数组？

在数学上，我们要维护的位置 $i$ 的函数是：


$$F(i) = \text{slope} \times i + \text{const}$$


由于 $i$ 是不断变化的，它既参与了一次项（$\text{slope} \times i$），也参与了常数项（$\text{const}$）。这两部分的累加**不能混在一起**：

1. **`d_slope`**：专门用来管理和记录这一段区间内，斜率（变化率）发生了多少改变。
2. **`d_const`**：专门用来记录截距，也就是基础高度（常数项）发生了多少改变。

对这两个维度分别做最基础的**一阶区间差分**（即代码里的 `add_line`）：

```python
def add_line(L, R, slope, const):
    d_slope[L] += slope
    d_slope[R + 1] -= slope
    
    d_const[L] += const
    d_const[R + 1] -= const

```

它带来的好处是：无论中间那段斜坡有多长，我们都只需要在左端点 $L$ 和右端点 $R+1$ 处打上标记。

### 最后怎么完美复原？

当所有的 $v$ 遍历完毕，所有折线的变化量都已经堆积在 `d_slope` 和 `d_const` 里面了。

我们只需要从左到右扫一遍（做一次前缀和），就能让当前位置 $i$ 准确拿到属于它的、叠加了成百上千次的最终斜率 `cur_slope` 和最终截距 `cur_const`。最后用 `cur_slope * i + cur_const` 轻轻一算，这一点的总高度（也就是总贡献）就出来了。

这种“双轨道差分”是处理**分段一次函数动态叠加**的通用神技，比去维护二阶差分更加直观且不容易写错。

这种转换利用了数学上的常用恒等式：


$$\text{MEX} = \sum_{v=1}^{n} [\text{MEX} \ge v]$$


这样一来，我们不需要去考虑那个会阻挡我们的数字 $k$（因为那是“恰好等于”才需要剔除的），而只需要专注于“要把 $0, 1, \dots, v-1$ 全部包住，最少需要多大的区间 $[l_0, r_0]$”。

随着 $v$ 从 $1$ 到 $n$ 从小到大遍历，这个必须包住的区间 $[l_0, r_0]$ 只会**单调扩张**。

### 核心数学模型的解析（基于你的分类）

对于一个确定的 $v$，所有合法的子数组 $[l, r]$ 必须满足 $l \le l_0$ 且 $r \ge r_0$。这样的子数组总共有 $(l_0 + 1) \times (n - r_0)$ 个。

现在我们看这些合法的子数组，有多少个覆盖了当前位置 $i$：

1. **当 $l_0 \le i \le r_0$（$i$ 在核心区间内部）：**
所有的合法子数组都必然跨越 $[l_0, r_0]$，所以必然也顺带覆盖了 $i$。
* **贡献次数：** $(l_0 + 1) \times (n - r_0)$ （是一个与 $i$ 无关的**常数**）


2. **当 $i < l_0$（$i$ 在核心区间左侧）：**
子数组的右端点 $r$ 依然有 $(n - r_0)$ 种选择；但左端点 $l$ 不能只到 $l_0$ 了，它必须进一步往左延伸到 $i$ 或更左边（即 $0 \le l \le i$），有 $(i + 1)$ 种选择。
* **贡献次数：** $(i + 1) \times (n - r_0) = (n - r_0) \cdot i + (n - r_0)$ （这是一个关于 $i$ 的**一次函数**）


3. **当 $i > r_0$（$i$ 在核心区间右侧）：**
子数组的左端点 $l$ 有 $(l_0 + 1)$ 种选择；右端点 $r$ 必须延伸到 $i$ 或更右边（即 $i \le r < n$），有 $(n - i)$ 种选择。
* **贡献次数：** $(l_0 + 1) \times (n - i) = -(l_0 + 1) \cdot i + (l_0 + 1) \cdot n$ （这同样是一个关于 $i$ 的**一次函数**）



---

### 一阶差分直接搞定

因为每一段关于 $i$ 的函数最多只有**一次项**，这意味着如果我们对 $i$ 这个维度做**一阶差分**，区间加一次函数就会变成区间加常数；如果我们做**二阶差分**，就能用真正的 $O(1)$ 来给全域打标记。

既然你已经清晰地梳理出了这三段一次函数，我们直接用你的逻辑把代码重构得极其优雅。这里我们使用两个差分数组 `d_slope`（维护一次项系数）和 `d_const`（维护常数项系数）。

### 优化后的 Python 代码实现（基于提示逻辑）

```python
import sys

def solve():
    input = sys.stdin.read
    data = input().split()
    if not data:
        return
    
    n = int(data[0])
    a = [int(x) for x in data[1:n+1]]
    
    # 记录 0-indexed 位置
    pos = [0] * n
    for i in range(n):
        pos[a[i]] = i
        
    # 用于维护一次函数分段加法的差分数组
    # F(i) = slope[i] * i + const[i]
    d_slope = [0] * (n + 1)
    d_const = [0] * (n + 1)
    
    # 辅助函数：给 i in [L, R] 这一段区间，加上一个一次函数: slope * i + const
    def add_line(L, R, slope, const):
        if L > R:
            return
        d_slope[L] += slope
        d_slope[R + 1] -= slope
        d_const[L] += const
        d_const[R + 1] -= const

    # 初始区间：由数字 0 决定
    l0 = pos[0]
    r0 = pos[0]
    
    # v 从 1 遍历到 n
    for v in range(1, n + 1):
        # 1. 第一段：i < l0
        # 贡献为: (n - r0) * i + (n - r0)
        if l0 > 0:
            add_line(0, l0 - 1, n - r0, n - r0)
            
        # 2. 第二段：l0 <= i <= r0
        # 贡献为常数: (l0 + 1) * (n - r0)
        add_line(l0, r0, 0, (l0 + 1) * (n - r0))
        
        # 3. 第三段：i > r0
        # 贡献为: -(l0 + 1) * i + (l0 + 1) * n
        if r0 < n - 1:
            add_line(r0 + 1, n - 1, -(l0 + 1), (l0 + 1) * n)
            
        # 为下一个 v 更新核心包裹区间
        if v < n:
            p_v = pos[v]
            if p_v < l0:
                l0 = p_v
            if p_v > r0:
                r0 = p_v

    # 还原差分
    ans = []
    cur_slope = 0
    cur_const = 0
    for i in range(n):
        cur_slope += d_slope[i]
        cur_const += d_const[i]
        ans.append(cur_slope * i + cur_const)
        
    print(*(ans))

if __name__ == '__main__':
    solve()

```

### 为什么这个思路更好？

1. **告别了“边界阻挡”的恶心判断：** 在原方案中，我们需要判断 $P_k$ 在 $[L, R]$ 的左边、右边还是中间，分类讨论极其容易写挂。而基于 $\text{MEX} \ge v$ 的拆分，由于区间只有单调扩张，根本不存在“被中间卡住”的情况。
2. **完美的分段线性表现：** 你的推导直接把覆盖次数暴露成了三段非常干净的一次函数。代码中直接对 `slope` 和 `const` 进行一阶区间差分（对应代码里的 `add_line`），最后求一次前缀和就能把一次函数完美复原。
3. **极高的运行效率：** 每一档 $v$ 只需无脑调用 3 次 $O(1)$ 的差分边界修改，整个流程没有任何多余分支，跑满 $O(n)$ 极其轻松。
