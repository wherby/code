### 核心结论与证明

1. **每条边（无论是树边还是非树边）对全图“奇偶性和”的贡献永远是 0**：
* 任意选一条边 $(u, v)$，它会同时给 $u$ 和 $v$ 的度数各 $+1$。

* 从奇偶性（$\text{GF}(2)$ 域 / 模 2 意义）来看，**任何一条边的加入或删除，都不会改变该连通块内所有节点度数奇偶性的总和**。


2. **生成树决定了“连通块奇偶性和”的计算**：
* 既然非树边不改变连通块的奇偶性和，那么**仅靠生成树上的节点连通关系**，就已经完全确定了这个连通块能否实现“所有节点度数变为偶数”。
* 判定条件极其简洁：**当且仅当一个连通块内所有初始奇数度节点的个数为偶数时（即奇偶性和 $\equiv 0 \pmod 2$），该连通块才存在合法解。**


3. **非树边不影响“可行性”，只影响“方案数”**：
* **可行性**：只由“连通块奇偶性和”决定，生成树完全保留了连通性，因此用生成树就能判断。
* **构造解**：非树边提供的是“环”（自由度），改变非树边只会影响局部具体选了哪些边，但绝不会破坏全图奇偶性和为 0 的性质。

### 核心解题思路拆解

#### 1. 问题等价转换（奇偶性目标）

* 原图的每个节点（包含“湖外”节点 $v_{\text{out}}$）都有一个初始度数奇偶性 $\text{deg}_{\text{exist}}(v) \bmod 2$。
* 我们的目标是从可选边（$K$ 条候选桥）中选出若干条边，使得**对于每个节点 $v$，被选中的边覆盖 $v$ 的次数奇偶性等于 $\text{deg}_{\text{exist}}(v) \bmod 2$**。
* 这样，原度数与新边度数异或相加后，每个节点的总度数都将变为**偶数**，满足欧拉回路的度数条件。

#### 2. 处理多连通块（连通性约束）

* 可选边集构成的图可能包含多个连通分量。
* **合法性判别**：在一个连通分量内，能够通过选边改变节点奇偶性的充要条件是——**该连通分量内所有目标奇偶性（需要改变奇偶性的节点数）的总和必须为偶数**。如果某个连通分量内有奇数个“奇数度节点”，则无解。
* 如果连通性不足（如存在无法连通到起点 $v_{\text{out}}$ 且包含必须走的边的连通块），则直接判定不可行。

#### 3. 生成树 + 树上差分 / 树上贪心（反向传递）

在每个连通分量中：

1. **构建生成树**：提取该连通分量的一个生成树（Spanning Tree），将非树边（Back-edges）和树边分开。
2. **树上反向贪心（从叶子到根）**：
* 树的结构决定了：**除了根节点外，任何一个节点 $u$ 到其父节点的树边，是唯一能独立控制节点 $u$ 奇偶性的边**。
* 因此，我们自底向上（按拓扑序/后序遍历）处理每个节点：
* 如果当前节点 $u$ 的当前奇偶性仍为奇数（需要改变），则**必须选择** $(u, \text{parent}(u))$ 这条树边，并将其影响向上传递给 $\text{parent}(u)$。
* 如果当前节点 $u$ 为偶数，则**不能选择** $(u, \text{parent}(u))$ 这条树边。




3. **消除非树边（自由变量）**：非树边形成环，任意选择非树边组合都会产生一个自由度，可以通过线性基或树上差分来枚举/构造具体解。

#### 4. 验证与最终检查（测试最优解）

* **度数验证**：检查选择这些边后，所有节点的总度数是否均为偶数。
* **欧拉连通性验证**：所有包含边（原有的或新增的）的节点，必须属于包含起点 $v_{\text{out}}$ 的同一个连通分量中（孤立的 0 度节点除外）。
