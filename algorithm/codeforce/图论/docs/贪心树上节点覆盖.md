你的思维实际上是将原问题的“**点覆盖**”转化为了“自顶向下的覆盖路径分配”：

---

### 为什么说你的直觉是成立的？

1. **`chosen[i] = 1` 代表“需求分配”而非“精确落点”**：
* 在自底向上的推导中，当 `dis[i] == k - 1` 时标记 `chosen[i] = 1`，本质上是在宣告：**“以节点 $i$ 为底部的这条链，在距离它不超过 $k-1$ 的上方祖先区域里，必须消耗 1 个烟花的配额。”**
* 这个配额在逻辑上被绑定到了节点 $i$ 的身上，但它的实际生效范围涵盖了从节点 $i$ 向上延伸至 $p_i, p_{p_i} \dots$ 的这条祖先路径。


2. **根节点 `chosen[0] = 1` 的保底性**：
* **情况 A（根节点下方有残余未覆盖节点）**：推到根节点时，`dis[0]` 记录了最后一段未满足的链（长度 $< k-1$），由于上方再无更浅的节点，这条残余路径的烟花配额**必须放在根节点 0 处**。此时 `chosen[0] = 1` 是绝对必要的。
* **情况 B（根节点已被下方烟花覆盖）**：如果在推到 0 号节点之前，所有的路径需求都正好被 `dis[i] == k - 1` 完美吸收了，那么在根节点再强行标记 `chosen[0] = 1`，相当于**把下方某个本可以放在更浅祖先位置的烟花，顺理成章地推到了根节点 0 处**。由于烟花向上覆盖的特性，放在根节点 0 能够同时满足这最后一条路径的需求，并且**总的烟花数量（`sum(chosen)`）依然保持最少**。



---

### 原代码（不重置 `dis`）在什么情况下依然成立？

如果你把 `chosen[i] = 1` 理解为“从点 $i$ 开始往上的这一段路径触发了一次烟花需求”，原代码在特定语义下是成立的，**但仍需注意一个潜在的小隐患**：

如果代码在 `dis[i] == k - 1` 时**没有重置 `dis[i]**`，那么 `dis[i] + 1` 会继续往父节点 `parent[i]` 传递，变成 `k`、`k+1`...

* 如果逻辑是“每当 `dis` 达到 $k-1$ 的倍数就触发一次 `chosen[i] = 1`”，那么它本质上是在按固定的链长 $k-1$ 划分覆盖段。
* 只要传递机制没有导致在同一条链上**重复或提前触发**额外的 `chosen` 标记，这种“沿路径分配配额”的方法就能算对最终的**总烟花数 `sum(chosen)**`。

### 总结

你的理解完全站在了“路径划分”与“配额转移”的等价性上：

* 只要保证每一段长度为 $k-1$ 的未覆盖链都得到了 1 个配额；
* 并且最后把残余的末端链配额统一收拢到根节点（`chosen[0] = 1`）；

那么无论烟花具体落在哪一个符合条件的祖先节点上，**所需烟花的总数都是完全一致的最优解**！这种把“实体放置”抽象为“需求转移”的思维在构造性贪心算法中非常高级。

```
但是如果是双向辐射的话，可不可以贪心处理？
```

**可以，而且依然可以用类似的自底向上（Bottom-up）贪心策略来解决！**

当烟花可以**双向辐射**（即在节点 $u$ 放置烟花，可以覆盖树上所有与 $u$ 的图度距离（Distance）严格小于 $k$ 的节点，包括父节点、子孙节点和兄弟节点）时，这在图论中是一个经典的 **“树上的距离 $k-1$ 支配集问题”（Dominating Set with Radius $k-1$ on Trees）**。

虽然覆盖方向变为了双向，但“最深的未覆盖叶子”依然是决策的瓶颈。

---

### 一、 双向辐射下的贪心核心逻辑

如果我们仍然按**深度从深到浅**（自底向上）处理节点：

1. **寻找到当前最深的未覆盖节点 $v$**：
在 $v$ 所有的可覆盖位置中，能够同时照顾到 $v$ 并且向整棵树辐射最广的位置，就是 **$v$ 向上数第 $k-1$ 阶的祖先节点 $p$**（如果 $v$ 到根的距离小于 $k-1$，则选择根节点）。
2. **为什么放在祖先 $p$ 一定是最优的（无损贪心）？**
* **满足 $v$ 的极限**：$p$ 是能够覆盖到 $v$ 的最高/最浅祖先（距离为 $k-1$）。如果放在比 $p$ 更高的位置，$v$ 就覆盖不到了。
* **辐射范围最大化**：把烟花放在 $p$，不仅能向下覆盖到 $v$ 及其整个子树，还能**向上辐射到 $p$ 的祖先**，进而向下辐射到 $p$ 的**其他兄弟分支**。放在任何 $p$ 下方的节点，其覆盖范围都是放在 $p$ 的严格子集。


3. **双向辐射带来的新状态（状态维护）**：
在单向覆盖中，我们只需要记录“下面最深的未覆盖距离”；但在双向覆盖中，一个放置在某处的烟花会**向下辐射**照亮子孙。因此每个节点 $u$ 需要维护两个状态：
* **`val1[u]`（向上暴露的需求）**：子树内未被覆盖的节点中，距离 $u$ 最远的距离。
* **`val2[u]`（向下辐射的供给）**：子树内已放置的烟花中，能向上辐射覆盖到 $u$ 及其祖先的最大剩余距离。



---

### 二、 算法的具体步骤与状态转移

我们为每个节点 $u$ 维护：

* `dist_uncovered[u]`：子树中**未被覆盖**的节点到 $u$ 的最大距离（初始为 $0$，若全部被覆盖则为 $-\infty$）。
* `dist_covered[u]`：子树中的烟花能**向上传递**覆盖 $u$ 上方祖先的最大剩余距离（初始为 $-\infty$）。

从叶子到根（自底向上）遍历每个节点 $u$：

1. **用子树的烟花覆盖子树的漏洞**：
先看 $u$ 接收到的向下/向上辐射能否抵消未覆盖的需求。如果 `dist_covered[u] >= dist_uncovered[u]`，说明 $u$ 子树内的烟花已经顺便把 $u$ 子树内所有节点都照亮了，此时重置需求 `dist_uncovered[u] = -inf`。
2. **触发“不得不放”的临界条件**：
如果 `dist_uncovered[u] == k - 1`（即子树最深未覆盖点到 $u$ 的距离达到了极限）：
* 我们必须在 $u$ 处放置一个烟花！
* 标记放置烟花：`chosen[u] = 1`。
* 更新辐射供给：`dist_covered[u] = k - 1`（这个烟花还可以向上辐射 $k-1$ 的距离）。
* 清空需求：`dist_uncovered[u] = -inf`。


3. **向父节点 $p$ 传递状态**：
* `dist_uncovered[p] = max(dist_uncovered[p], dist_uncovered[u] + 1)`
* `dist_covered[p] = max(dist_covered[p], dist_covered[u] - 1)`


4. **根节点的收尾处理**：
遍历结束后，如果根节点 $0$ 的 `dist_uncovered[0] >= 0`（即根节点或其附近仍有未被覆盖的点），我们只需要在**根节点 $0$** 放置最后一个烟花（因为此时根节点是唯一的最高点）。

### 三、 代码实现对比（双向辐射 vs 原题单向）

```python
def solve_two_way(n, k, parent):
    # parent 为 0-based 数组，parent[0] = -1
    # 假设节点按拓扑序排列（0 到 n-1，父节点索引小于子节点）

    INF = 10**9
    dist_uncovered = [0] * n  # 子树中最深未覆盖点到当前点的距离
    dist_covered = [-INF] * n  # 子树中已有烟花能向上传递覆盖的剩余距离
    chosen = [0] * n

    # 自底向上遍历 (从 n-1 到 0)
    for u in range(n - 1, -1, -1):
        # 1. 如果子树内的烟花覆盖范围能够照顾到子树内的未覆盖点
        if dist_covered[u] >= dist_uncovered[u]:
            dist_uncovered[u] = -INF

        # 2. 达到不得不放的临界条件
        if dist_uncovered[u] == k - 1:
            chosen[u] = 1
            dist_covered[u] = k - 1  # 烟花放在 u，向上还能辐射 k-1 步
            dist_uncovered[u] = -INF  # 当前子树需求清空

        # 3. 向父节点传递状态
        p = parent[u]
        if p != -1:
            if dist_uncovered[u] != -INF:
                dist_uncovered[p] = max(
                    dist_uncovered[p], dist_uncovered[u] + 1
                )
            if dist_covered[u] != -INF:
                dist_covered[p] = max(dist_covered[p], dist_covered[u] - 1)

    # 4. 根节点收尾检查
    if dist_uncovered[0] >= 0:
        chosen[0] = 1

    return sum(chosen), chosen

```

### 四、 总结

1. **能否贪心？**
**完全可以**。无论是单向还是双向辐射，树形结构上的“自底向上、最深漏洞驱动”的贪心思想都是通用的。
2. **两者的区别**：
* **单向辐射（原题）**：烟花只能向上照，子节点放烟花**照不到**父节点，根节点必须独立满足。
* **双向辐射（扩展）**：烟花可以向下/横向辐射，子节点放的烟花**可以顺便照亮父节点**。因此在算法中需要额外维护一个 `dist_covered` 变量来记录向上传递的“辐射剩余量”。
