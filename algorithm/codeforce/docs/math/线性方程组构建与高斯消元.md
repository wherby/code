这个转换非常巧妙！问题的关键在于：**我们必须固定一个具体的 $n$ 值，才能把抽象的代数等式变成可以计算的具体向量方程。**

我们来一步步拆解为什么代码直接写了 `solve(v2[k - 1] - v2[i])`：

---

### 1. 题目的原始等式

题目的目标是让下式对所有满足条件的数列在 $n > b_k$ 时**恒成立**：


$$F_n = \sum_{i=1}^k c_i F_{n-b_i} = c_1 F_{n-b_1} + c_2 F_{n-b_2} + \dots + c_k F_{n-b_k}$$

由于这个等式对所有 $n > b_k$ 都必须成立，我们只需要**挑选一个最方便计算的具体 $n$ 值**代入即可。

---

### 2. 为什么选 $n = b_k + 1$？

因为数列的递推定义是从 $F_1, F_2, \dots, F_k$ 开始的，**下标必须 $\ge 1$**。

在序列 $b$ 中，假设 $b_k$ 是最大的值（即 $b_1 < b_2 < \dots < b_k$）：

* 为了让右边下标最小的一项 $F_{n-b_k}$ 刚好落到基底的第一项 $F_1$，最直接的选法就是令：

$$n = b_k + 1$$



把 $n = b_k + 1$ 代入原等式：

* **左边**变成：$F_{b_k + 1}$
* **右边**变成：$\sum_{i=1}^k c_i F_{(b_k + 1) - b_i} = \sum_{i=1}^k c_i F_{(b_k - b_i) + 1}$

---

### 3. 下标与 `solve(x)` 函数的参数对应关系

在我们的 `solve(x)` 函数中，它的定义是：

> **`solve(x)` 求的是第 $F_{x+1}$ 项在基底 $(F_1, F_2, \dots, F_k)$ 上的展开向量。**

注意参数 $x$ 和项数 $F_{\text{下标}}$ 的关系：**$x = \text{下标} - 1$**。

我们来看看两边各项对应的 $x$ 是什么：

#### ① 右边的第 $i$ 项 $F_{(b_k - b_i) + 1}$

* 它的**下标**是：$(b_k - b_i) + 1$
* 传入 `solve()` 的参数 $x$ 就是：

$$x = \text{下标} - 1 = (b_k - b_i + 1) - 1 = \mathbf{b_k - b_i}$$


* 在代码中，`v2` 数组存储的就是 sequence $\{b_i\}$（从 0 开始索引，所以 $b_k$ 就是 `v2[k - 1]`，$b_i$ 就是 `v2[i]`）。
* 于是传入的参数自然就是：
`v2[k - 1] - v2[i]`

#### ② 左边的目标项 $F_{b_k + 1}$

* 它的**下标**是：$b_k + 1$
* 传入 `solve()` 的参数 $x$ 就是：

$$x = (b_k + 1) - 1 = \mathbf{b_k}$$


* 在代码中对应的就是：`solve(v2[k - 1])`

---

### 4. 总结对比

| 代数公式中的项 | 具体的下标 ($n = b_k + 1$) | 对应 `solve(x)` 的 $x$ 参数 | 代码写法 |
| --- | --- | --- | --- |
| **右边第 $i$ 项** | $F_{(b_k - b_i) + 1}$ | $x = b_k - b_i$ | `solve(v2[k - 1] - v2[i])` |
| **左边目标项** | $F_{b_k + 1}$ | $x = b_k$ | `solve(v2[k - 1])` |

无论 $b_i$ 的具体数值是多少，只要令 $n = b_k + 1$，每一项到 $F_1$ 的相对距离 $b_k - b_i$ 就被固定下来了，因此直接调用 `solve(v2[k - 1] - v2[i])` 就可以完美拿到该项在 $k$ 维基底上的展开向量！

```
构建线性方程组 与 高斯消元求解
```

这段代码实现了算法的最后一步：**构建线性方程组，并用模 $10^9+7$ 意义下的高斯-约当消元法（Gaussian-Jordan Elimination）解出系数序列 $\{c_1, c_2, \dots, c_k\}$**。

整个过程可以分为**构建增广矩阵**、前向消元（化上三角）**和**反向回代（化对角阵/主元形式）三个阶段。

---

### 一、 构建增广矩阵（前 12 行）

```python
equations = [[0] * (k + 1) for _ in range(k)]

# 1. 填入方程组左边的系数矩阵（0 到 k-1 列）
for i in range(k):
    tmp = solve(v2[k - 1] - v2[i])
    for j in range(k):
        equations[j][i] = tmp[j]

# 2. 填入方程组右边的常数项向量（第 k 列，即增广列）
tmp = solve(v2[k - 1])
for j in range(k):
    equations[j][k] = tmp[j]

```

#### 逻辑解析：

* **目标等式**：$F_n = \sum_{i=1}^k c_i F_{n-b_i}$
* **设定 $n = b_k + 1$**：
* 右边第 $i$ 项为 $F_{(b_k - b_i) + 1}$。调用 `solve(v2[k - 1] - v2[i])` 计算其在基底 $(F_1, \dots, F_k)$ 上的展开向量 `tmp`，将其**按列**填入矩阵 `equations` 的第 $i$ 列。
* 左边目标项为 $F_{b_k + 1}$。调用 `solve(v2[k - 1])` 计算其展开向量 `tmp`，作为方程的常数项填入增广矩阵的**最后一列（第 $k$ 列）**。



执行完这部分后，`equations` 是一个 $k \times (k+1)$ 的增广矩阵，表示方程 $M \mathbf{c} = \mathbf{v}$。

---

### 二、 前向消元 / 上三角化（第 14 到 40 行）

这部分代码的目标是把矩阵通过**初等行变换**化为上三角矩阵。

```python
pt = 0  # 指向当前正在寻找主元的列

for i in range(k):
    chosen = -1
    # 1. 寻找主元：在当前及往后的列 pt 中，从第 i 行向下找一个非零元素
    while pt < k + 1 and chosen == -1:
        for j in range(i, k):
            if equations[j][pt]:
                chosen = j
                break
        pt += 1
    
    pt -= 1  # 修正 while 循环中多自增的 1，此时 pt 为真正的主元列
    
    # 2. 行交换：将选中的主元行 chosen 交换到第 i 行
    if chosen != i:
        equations[i], equations[chosen] = equations[chosen], equations[i]
    
    if pt == k + 1: break  # 若找不到非零列，提前退出
    
    # 3. 归一化（主元化为 1）：在模 mod 意义下乘上主元的乘法逆元
    v = pow(equations[i][pt], -1, mod)  # 相当于 v = 1 / equations[i][pt] (mod 10^9+7)
    for j in range(pt, k + 1):
        equations[i][j] = equations[i][j] * v % mod
    
    # 4. 消去下方元素：用第 i 行把下方 (i+1 到 k-1 行) 在 pt 列的元素消成 0
    for j in range(i + 1, k):
        w = (-equations[j][pt]) % mod
        for x in range(pt, k + 1):
            equations[j][x] += equations[i][x] * w
            equations[j][x] %= mod

```

#### 逻辑解析：

1. **模逆元处理**：在有限域（模质数）下，除法等于乘以乘法逆元（利用费马小定理 `pow(a, -1, mod)` 对应 $a^{mod-2} \bmod mod$）。
2. **指针 `pt` 的作用**：防止出现某列全为 0 时卡住的情况，自动跳到下一列寻找主元。
3. **消去下方**：对第 $j$ 行（$j > i$），乘以 `w = -equations[j][pt]` 并加到第 $j$ 行上，使第 $j$ 行第 `pt` 列的分量变成 $0$。

---

### 三、 反向回代 / 对角化（第 42 到 53 行）

将上三角矩阵进一步消去上方的非零元素，直接把左边 $k \times k$ 矩阵化为**阶梯化/对角阵形式**。

```python
for i in range(k - 1, -1, -1):  # 从最后一行往回倒推
    for j in range(k + 1):
        if equations[i][j]:  # 找到第 i 行的首个非零项（主元所在位置，通常就是 j = i）
            
            # 消去第 i 行上方所有行（第 0 到 i-1 行）在第 j 列的元素
            for x in range(i):
                w = (-equations[x][j]) % mod
                for y in range(j, k + 1):
                    equations[x][y] += equations[i][y] * w
                    equations[x][y] %= mod
            
            break  # 找到主元并消去上方元素后，处理上一行

```

#### 逻辑解析：

* **反向遍历**：从下往上（`i` 从 `k-1` 递减到 `0`）。
* **找到首个非零列 `j**`：第 `i` 行的主元在第 `j` 列（因为前向消元后，主元已被归一化为 1）。
* **向上消元**：用第 `i` 行的方程式将上方行（$x < i$）在第 `j` 列的系数完全消除掉。
* **最终效果**：消元完成后，矩阵左边的 $k \times k$ 部分彻底变成了**单位矩阵**。
此时，增广矩阵的最后一列 `equations[0][k], equations[1][k], ..., equations[k-1][k]` 就**直接是解向量 $c_1, c_2, \dots, c_k$**！
