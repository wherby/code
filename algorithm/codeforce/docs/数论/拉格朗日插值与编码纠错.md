```
所以这个题目其实有两次插值行为？ 第一次是为了去除坏点，第二次是求常数项？
```

**是的，你的理解非常到位！本质上就是“两次插值”：**

1. **第一次“隐式插值”（找坏点）：**
* **目的：** 验证哪一个点是坏点。
* **做法：** 我们并没有把整条曲线插值求出来，而是利用拉格朗日插值的性质，只提取并计算了 $x^k$ 项（最高次项）的系数。通过检查哪个点被排除后能让最高次项系数归零，来精准锁定被篡改的坏点。


2. **第二次“显式插值”（求常数项）：**
* **目的：** 还原真正的宝箱密码 $P(0)$。
* **做法：** 排除掉坏点后，用剩下的 $k+1$ 个干净点做一次标准的拉格朗日插值，直接带入 $x = 0$，求出常数项 $P(0)$。



---

### 一句总结

> **第一次插值是“侦探校验”**（看最高次项系数是不是 $0$，用来抓贼）；
> **第二次插值是“解密开锁”**（用干净的点求 $P(0)$，拿主密钥）。

```
但是两个插值的求解过程是不一样的？
```
**你的直觉非常敏锐！**

表面上看，第一次是算 `val += saved_vals[j] * (xs[i] - xs[j])`，第二次是算 `A = A * (-xs[v])`，形式完全不同。

但从数学本质上讲：**这两个过程使用的完全是【同一个拉格朗日插值公式】，只是因为“代入的值”不同，导致公式被简化成了不同的形态。**

我们来看看公式在两次应用中，是怎么变身成不同样子的：

---

### 一、 核心公式：标准的拉格朗日插值

假设用剩下的干净点插值还原出多项式 $f(x)$，它的**通用标准公式**是：

$$f(x) = \sum_{j \neq i} y_j \prod_{v \neq i, j} \frac{x - x_v}{x_j - x_v}$$

在这两次操作中，我们只是在对这个公式做**不同的“截取”或“代入”**：

---

### 二、 第二次插值：直接求 $P(0)$（最直观的代入）

这次的目标非常简单直接：**求 $x = 0$ 时的函数值 $f(0)$**。

我们直接把 **$x = 0$** 代入上面的标准公式：

$$f(0) = \sum_{j \neq i} y_j \prod_{v \neq i, j} \frac{\mathbf{0} - x_v}{x_j - x_v}$$

看代码里的计算：

* **分子 `A**`：`y_j` 乘以一连串 $(0 - x_v)$，即 `A = ys[j] * (-xs[v])`
* **分母 `B**`：一连串 $(x_j - x_v)$，即 `B = (xs[j] - xs[v])`

**这完全就是把 $x=0$ 硬生生套进标准公式里算出来的！**

---

### 三、 第一次插值：提取 $x^k$ 次项系数（公式展开后的变形）

这次的目标不是求某个 $x$ 的具体值，而是要**把整个多项式 $f(x)$ 展开，看 $x^k$ 前面的那个系数**。

我们把标准公式的分子展开：

$$\prod_{v \neq i, j} (x - x_v) = \underbrace{\mathbf{1} \cdot x^k}_{\text{最高次项}} - \left(\sum_{v \neq i, j} x_v\right) x^{k-1} + \dots$$

注意！在这个乘积展开式中，$x^k$ 的系数**永远是 $1$**！

所以，整个多项式 $f(x)$ 展开后，贡献给 $x^k$ 的总系数就是：

$$\text{系数} = \sum_{j \neq i} \frac{y_j}{\prod_{v \neq i, j} (x_j - x_v)}$$

为了不让分母因为缺失了 $v=i$ 项而每次重复算，我们在分子分母同乘以 $(x_j - x_i)$：

$$\text{系数} = \sum_{j \neq i} \frac{y_j (x_j - x_i)}{\prod_{v \neq j} (x_j - x_v)}$$

注意看，这里的 $\frac{y_j}{\prod_{v \neq j} (x_j - x_v)}$ 正好就是我们在代码开头预处理的 **`saved_vals[j]`**！

所以，提取出的 $x^k$ 系数就变成了：


$$\text{系数} = \sum_{j \neq i} \text{saved\_vals}[j] \times (x_j - x_i)$$

这就是你代码里第一次插值校验时写的 `val += saved_vals[j] * (xs[i] - xs[j])`！

---

### 四、 总结对比

| 操作 | 数学本质 | 在标准公式中做的事情 | 代码展现出来的样子 |
| --- | --- | --- | --- |
| **第一次插值** | **求多项式的系数** | 不代入具体的 $x$，而是把公式展开，只**把 $x^k$ 的系数提出来**，看它是不是 $0$ | 经过数学提公因式简化后，变成了非常简单的 `saved_vals[j] * (xs[i] - xs[j])` 累加 |
| **第二次插值** | **求多项式的值** | 直接**代入 $x = 0$** | 最原汁原味的拉格朗日公式：分子算 $\prod(0 - x_v)$，分母算 $\prod(x_j - x_v)$ |

所以，**它们不是两个独立的算法，而是同一个拉格朗日插值公式在“求系数”和“求点值”这两种不同需求下的不同数学形态！**

# 拉格朗日插值 是什么意思，为什么这样做之后能找到k方系数的值？
---


```
拉格朗日插值 是什么意思，为什么这样做之后能找到k方系数的值？
```

### 1. 什么是拉格朗日插值？

简单来说，**拉格朗日插值（Lagrange Interpolation）是一种“用若干个已知的点，去反推并拼凑出穿过这些点的多项式”的数学方法。**

假设我们知道平面上有 $N$ 个点 $(x_1, y_1), (x_2, y_2), \dots, (x_N, y_N)$，我们想找到一个多项式 $f(x)$，使得对每一个 $j$，都有 $f(x_j) = y_j$。

拉格朗日极其巧妙地把这个复杂的寻找过程，拆解成了若干个“机关函数”**（学名叫做**基函数 $\ell_j(x)$）：

#### 第一步：设计“开关”基函数 $\ell_j(x)$

拉格朗日构造了一个特殊的基函数 $\ell_j(x)$，它具备这样的**开关特性**：

* 当你代入 $x = x_j$ 时，$\ell_j(x_j) = 1$（开关打开）。
* 当你代入**其他任何给定的 $x_v$** ($v \neq j$) 时，$\ell_j(x_v) = 0$（开关关闭）。

如何构造出这样的函数？很简单，把所有其他点的根乘起来作为分子，再除以对应的常数：


$$\ell_j(x) = \frac{(x - x_1)(x - x_2)\dots(x - x_v)\dots}{(x_j - x_1)(x_j - x_2)\dots(x_j - x_v)\dots} = \prod_{v \neq j} \frac{x - x_v}{x_j - x_v}$$

* 你试着代入 $x = x_v$：分子中包含 $(x_v - x_v) = 0$，整个式子直接归零！
* 你试着代入 $x = x_j$：分子分母一模一样，约分后恰好等于 $1$！

#### 第二步：组装最终的多项式 $f(x)$

有了这个“开关”，我们只需要把每个点对应的 $y_j$ 乘上去，再全部加起来：


$$f(x) = \sum_{j} y_j \cdot \ell_j(x) = \sum_{j} y_j \prod_{v \neq j} \frac{x - x_v}{x_j - x_v}$$

当我们将某个 $x_i$ 代入 $f(x)$ 时，只有第 $i$ 项的基函数是 $1$，其余所有项的基函数全部是 $0$，所以 $f(x_i) = y_i \cdot 1 + 0 + 0... = y_i$！完美穿过了所有给定的点！

---

### 2. 为什么这样做之后，能拿到 $x^k$ 次项系数的值？

在我们的问题中，排除第 $i$ 个点后，手头上剩下 **$k+1$ 个点**。
用这 $k+1$ 个点构造出的拉格朗日插值多项式 $f(i)(x)$ 的展开形式如下：

$$f(i)(x) = \sum_{j \neq i} y_j \cdot \ell_j(x) = \sum_{j \neq i} y_j \prod_{v \neq i, j} \frac{x - x_v}{x_j - x_v}$$

我们关注的是：**把这个复杂的式子展开后，最高次项 $x^k$ 的系数到底是多少？**

我们拆开基函数 $\ell_j(x)$ 来看：


$$\ell_j(x) = \frac{\overbrace{(x - x_1)(x - x_2)\dots (\text{跳过 } x_i \text{ 和 } x_j) \dots (x - x_{k+2})}^{k \text{ 个括号相乘}}}{\prod_{v \neq i, j} (x_j - x_v)}$$

1. **看分子**：分子是由 $k$ 个形如 $(x - x_v)$ 的一次因式相乘得到的。如果我们把这个分子完全展开，最高次方项显然就是把所有因式里的 $x$ 乘在一起，即 **$x^k$**。并且它的系数是 $1$。
2. **看分母**：分母纯粹是由常数相减相乘构成的，没有任何变量 $x$，所以它就是一个固定的数值常数：$\prod_{v \neq i, j} (x_j - x_v)$。

因此，第 $j$ 项基函数 $\ell_j(x)$ 展开后，贡献给 $x^k$ 的系数就是：


$$\text{项 } j \text{ 对 } x^k \text{ 的系数} = \frac{1}{\prod_{v \neq i, j} (x_j - x_v)}$$

再结合外面的系数 $y_j$，将每一项贡献给 $x^k$ 的系数累加起来，就得到了整个多项式 $f(i)(x)$ 的 $x^k$ 项的总系数：

$$\text{Coeff}(x^k) = \sum_{j \neq i} y_j \cdot \frac{1}{\prod_{v \neq i, j} (x_j - x_v)}$$

---

### 总结逻辑闭环

1. **拉格朗日插值**提供了一种把已知点转化为多项式公式的手段。
2. **提取系数**：因为拉格朗日基函数的分子展开后最高项就是 $x^k$，其系数只需把所有分母的常数项提取出来即可。
3. **检验坏点**：题目已知原本正确的多项式最高只有 $k-1$ 次（即 $x^k$ 项系数**必须为 $0$**）。如果算出来的 $x^k$ 系数等于 $0$，就证明我们排除的那一点正好是坏点，剩下的点拼凑出了真正的原多项式！

这两个提示给出了一个极其巧妙且更高效的视角！我们不需要每次都显式地去计算 $P(0)$，而是利用多项式的**次数特征**直接锁定那个被篡改的坏点。

我们把这两个提示的数学本质和优化思路一步步拆解展开：

---

### 一、 提示 1 的本质：用“最高次项系数”来做校验

题目明确说明：原多项式 $P(x)$ 的次数**至多是 $k-1$ 次**。

假设我们排除了第 $i$ 个点，用剩下的 $k+1$ 个点做拉格朗日插值，构造出一个次数**至多为 $k$ 次**的多项式 $f(i)$：

$$f(i)(x) = \sum_{j \neq i} y_j \prod_{v \neq i, j} \frac{x - x_v}{x_j - x_v}$$

* 如果我们排除的第 $i$ 个点**恰好是坏点**，那么剩下的 $k+1$ 个点全都在原多项式 $P(x)$ 上。插值出来的 $f(i)(x)$ 其实就是 $P(x)$ 本身！
* 因为 $P(x)$ 的次数最高只有 $k-1$，所以 $f(i)(x)$ 的 **$x^k$ 项系数必须恰好等于 $0$**！
* 展开插值公式中 $x^k$ 的系数，就能得到提示里的等式：

$$\text{Coeff}(x^k) = \sum_{j \neq i} y_j \cdot \frac{1}{\prod_{v \neq i, j}(x_j - x_v)} = 0 \pmod{10^9+7}$$



这就是判断排除第 $i$ 个点后剩下的 $k+1$ 个点是否全为真点的**绝对标准**。

---

### 二、 提示 2 的巧妙推导：提取公共部分

如果直接对每个 $i$ 重新算上面的式子，复杂度是 $O(k^3)$。提示 2 告诉我们怎么通过分子分母同乘一个项，把式子化简。

注意看分母：$\prod_{v \neq i, j}(x_j - x_v)$ 相比于完整的乘积 $\prod_{v \neq j}(x_j - x_v)$，**仅仅少了一项 $(x_j - x_i)$**！

因此，我们在分子分母同时乘以 $(x_j - x_i)$：

$$\frac{1}{\prod_{v \neq i, j}(x_j - x_v)} = \frac{x_j - x_i}{(x_j - x_i) \prod_{v \neq i, j}(x_j - x_v)} = \frac{x_j - x_i}{\prod_{v \neq j}(x_j - x_v)}$$

把这个代回 $x^k$ 系数为 $0$ 的条件中：

$$0 = \sum_{j \neq i} (x_j - x_i) \cdot \frac{y_j}{\prod_{v \neq j}(x_j - x_v)} \pmod{10^9+7}$$

看！关键的突破来了：**分母部分 $\prod_{v \neq j}(x_j - x_v)$ 已经与被排除的 $i$ 完全无关了！**

---

### 三、 从 $O(k^3)$ 到 $O(k)$ 的终极优化

定义常数 $C_j$：


$$C_j = \frac{y_j}{\prod_{v \neq j}(x_j - x_v)} \pmod{10^9+7}$$

只要我们预先花了 $O(k^2)$ 的时间把所有的 $C_j$（共有 $k+2$ 个）算出来，校验公式就变成了：

$$0 = \sum_{j \neq i} (x_j - x_i) \cdot C_j \pmod{10^9+7}$$

把括号展开：

$$\sum_{j \neq i} (x_j - x_i) C_j = \sum_{j \neq i} x_j C_j - x_i \sum_{j \neq i} C_j$$

设总体累加和为：

* $S_0 = \sum_{j=1}^{k+2} C_j \pmod{10^9+7}$
* $S_1 = \sum_{j=1}^{k+2} x_j C_j \pmod{10^9+7}$

那么排除第 $i$ 个点后的校验值可以用 $O(1)$ 的时间求出：

$$\text{Check}(i) = (S_1 - x_i C_i) - x_i (S_0 - C_i) \pmod{10^9+7}$$

只要找到那个让 $\text{Check}(i) \equiv 0 \pmod{10^9+7}$ 的下标 $i$，它就是**被篡改的坏点**！

找到坏点 $i$ 之后，我们再用剩下的 $k+1$ 个干净点做一次标准的拉格朗日插值算出 $P(0)$ 即可。

---

### 四、 快速算法实现代码

```python
MOD = 10**9 + 7

def solve(k, points):
    N = k + 2
    x = [p[0] for p in points]
    y = [p[1] for p in points]
    
    # 1. 预计算每个 j 的 C_j = y_j / \prod_{v != j} (x_j - x_v)
    C = []
    for j in range(N):
        denom = 1
        for v in range(N):
            if v != j:
                denom = (denom * (x[j] - x[v])) % MOD
        # 费马小定理求逆元
        inv_denom = pow(denom, MOD - 2, MOD)
        C.append((y[j] * inv_denom) % MOD)
        
    # 2. 预计算全局和 S0 和 S1
    S0 = sum(C) % MOD
    S1 = sum((x[j] * C[j]) % MOD for j in range(N)) % MOD
    
    # 3. O(1) 寻找坏点 i
    bad_index = -1
    for i in range(N):
        # 排除 i 点后的 sum(x_j * C_j) 和 sum(C_j)
        term1 = (S1 - x[i] * C[i]) % MOD
        term0 = (S0 - C[i]) % MOD
        
        check = (term1 - x[i] * term0) % MOD
        if check == 0:
            bad_index = i
            break
            
    # 4. 找到坏点后，用其余点拉格朗日插值计算 P(0)
    clean_indices = [j for j in range(N) if j != bad_index]
    
    # 我们只需要前 k 个干净点即可确定 P(x)
    use_indices = clean_indices[:k]
    
    P_0 = 0
    for j in use_indices:
        num = y[j]
        den = 1
        for m in use_indices:
            if m != j:
                num = (num * (0 - x[m])) % MOD
                den = (den * (x[j] - x[m])) % MOD
        term = (num * pow(den, MOD - 2, MOD)) % MOD
        P_0 = (P_0 + term) % MOD
        
    return bad_index, P_0

```

### 复杂度分析

1. **预处理 $C_j$**：需要计算 $N$ 个点的分母，时间复杂度 $O(k^2)$。
2. **寻找坏点**：计算 $S_0, S_1$ 耗时 $O(k)$，随后遍历检查每个 $i$ 仅耗时 $O(1)$，总共 $O(k)$。
3. **计算 $P(0)$**：只做一次 $k$ 个点的插值，耗时 $O(k^2)$。

总时间复杂度由原先的 $O(k^3)$ 完美优化到了 **$O(k^2)$**！结合多项式快速傅里叶变换（NTT）甚至可以进一步优化到 $O(k \log^2 k)$。
