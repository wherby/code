
[求最多的点共圆的数量](../../codeforce/几何图形/共圆点求解.py)
求由三点坐标确定的角度，通常是指**已知三个点 $A(x_1, y_1)$、$B(x_2, y_2)$、$C(x_3, y_3)$，计算以 $B$ 点为顶点的夹角 $\angle ABC$**。

最通用且便捷的方法是利用平面向量的数量积（点积）公式：

---

### 计算步骤

#### 1. 构建向量

以 $B$ 点为顶点，分别构造从 $B$ 指向 $A$ 和从 $B$ 指向 $C$ 的两个向量：

* $\vec{BA} = (x_1 - x_2, y_1 - y_2) = (a_1, a_2)$
* $\vec{BC} = (x_3 - x_2, y_3 - y_2) = (c_1, c_2)$

#### 2. 计算向量的点积与模长

* **点积**：$\vec{BA} \cdot \vec{BC} = a_1 c_1 + a_2 c_2$
* **$\vec{BA}$ 的模长**：$\vert{}\vec{BA}\vert{} = \sqrt{a_1^2 + a_2^2}$
* **$\vec{BC}$ 的模长**：$\vert{}\vec{BC}\vert{} = \sqrt{c_1^2 + c_2^2}$

#### 3. 计算余弦值与角度

利用余弦定理导出公式：


$$\cos \theta = \frac{\vec{BA} \cdot \vec{BC}}{\vert{}\vec{BA}\vert{} \cdot \vert{}\vec{BC}\vert{}} = \frac{a_1 c_1 + a_2 c_2}{\sqrt{a_1^2 + a_2^2} \cdot \sqrt{c_1^2 + c_2^2}}$$

最后通过反余弦函数（$\arccos$）求出角度：


$$\theta = \arccos(\cos \theta)$$

---

### 计算示例

已知三点：$A(1, 4)$、$B(1, 1)$、$C(5, 1)$，求 $\angle ABC$。

1. **构造向量**：
* $\vec{BA} = (1-1, 4-1) = (0, 3)$
* $\vec{BC} = (5-1, 1-1) = (4, 0)$


2. **代入公式**：
* 点积：$0 \times 4 + 3 \times 0 = 0$
* $\cos \theta = \frac{0}{3 \times 4} = 0$


3. **求解角度**：
* $\theta = \arccos(0) = 90^\circ$（或 $\frac{\pi}{2}$ 弧度）



---

### 拓展：三维坐标系

如果是空间三维坐标 $A(x_1, y_1, z_1)$、$B(x_2, y_2, z_2)$、$C(x_3, y_3, z_3)$，计算公式完全一致，只需将向量表示扩展至 3 个分量：

* $\vec{BA} = (x_1 - x_2, y_1 - y_2, z_1 - z_2) = (a_1, a_2, a_3)$
* $\vec{BC} = (x_3 - x_2, y_3 - y_2, z_3 - z_2) = (c_1, c_2, c_3)$

$$\cos \theta = \frac{a_1 c_1 + a_2 c_2 + a_3 c_3}{\sqrt{a_1^2 + a_2^2 + a_3^2} \cdot \sqrt{c_1^2 + c_2^2 + c_3^2}}$$
