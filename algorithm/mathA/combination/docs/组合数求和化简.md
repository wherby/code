## 提示 1：可以怎么走？

因为相邻两点的距离平方必须小于 2，而所有点都是整数坐标，所以两点的距离平方只能是 0 或 1。

- 距离为 0 意味着原地不动，但题目要求距离严格递减，所以不可能。
- 因此距离平方只能是 1，即每次**恰好走一格**（上下左右）。

同时，因为到原点的距离必须严格递减，所以每一步只能朝着让 \(|x|\) 或 \(|y|\) 变小的方向走。

换句话说：
- 如果 \(x > 0\)，只能向左走（\(x\) 减 1）
- 如果 \(x < 0\)，只能向右走（\(x\) 加 1）
- 如果 \(y > 0\)，只能向下走（\(y\) 减 1）
- 如果 \(y < 0\)，只能向上走（\(y\) 加 1）

把点映射到第一象限（取绝对值），不影响答案。于是问题变成：

> 从 \((x, y)\) 出发，每次可以向左走一格或向下走一格，求所有非空路径的总数。

## 提示 2：枚举终点，求和式化简

设最终停下的位置是 \((i, j)\)，其中 \(0 \le i \le x\)，\(0 \le j \le y\)。

从 \((x, y)\) 走到 \((i, j)\)，需要：
- 向左走 \(x - i\) 次
- 向下走 \(y - j\) 次

总步数是 \((x - i) + (y - j)\)，其中选择哪些步向左走，方案数为：

\[
\binom{(x-i)+(y-j)}{x-i}
\]

令 \(a = x - i\)，\(b = y - j\)，则 \(a\) 取遍 \(0 \sim x\)，\(b\) 取遍 \(0 \sim y\)。

所以总方案数是：

\[
\sum_{i=0}^{x} \sum_{j=0}^{y} \binom{(x-i)+(y-j)}{x-i}
= \sum_{a=0}^{x} \sum_{b=0}^{y} \binom{a+b}{a}
\]

---

## 化简第一步：对 \(b\) 求和

利用帕斯卡恒等式：

\[
\binom{a+b}{a} = \binom{a+b+1}{a+1} - \binom{a+b}{a+1}
\]

于是对 \(b\) 从 \(0\) 到 \(y\) 求和时，中间项会 Telescoping（裂项相消）：

\[
\sum_{b=0}^{y} \binom{a+b}{a}
= \binom{a+y+1}{a+1} - \binom{a}{a+1}
= \binom{a+y+1}{a+1}
\]

因为 \(\binom{a}{a+1} = 0\)。

---

## 化简第二步：对 \(a\) 求和

现在原式变成：

\[
\sum_{a=0}^{x} \binom{a+y+1}{a+1}
= \sum_{a=0}^{x} \binom{a+y+1}{y}
\]

再用一次帕斯卡恒等式：

\[
\binom{a+y+1}{y} = \binom{a+y+2}{y+1} - \binom{a+y+1}{y+1}
\]

对 \(a\) 从 \(0\) 到 \(x\) 求和，再次裂项相消：

\[
\sum_{a=0}^{x} \binom{a+y+1}{y}
= \binom{x+y+2}{y+1} - \binom{y+1}{y+1}
= \binom{x+y+2}{y+1} - 1
\]

---

## 最终答案

\[
\boxed{\binom{x+y+2}{y+1} - 1}
\]

或者等价地：

\[
\boxed{\binom{x+y+2}{x+1} - 1}
\]

---

## 帕斯卡恒等式的直觉

\[
\binom{a}{b} = \binom{a-1}{b} + \binom{a-1}{b-1}
\]

意思是从 \(a\) 个物品里选 \(b\) 个：

- 如果第一个物品**不选**，就从剩下的 \(a-1\) 个里选 \(b\) 个：\(\binom{a-1}{b}\)
- 如果第一个物品**选**，就从剩下的 \(a-1\) 个里再选 \(b-1\) 个：\(\binom{a-1}{b-1}\)

两种计数结果相同，所以等式成立。

## 总结

这道题的完整逻辑链是：

1. 距离约束 ⇒ 每次只能走一格，且只能朝原点方向走
2. 映射到第一象限 ⇒ 变成向右/向下走格子
3. 枚举终点 ⇒ 得到二重组合数求和
4. 两次裂项相消 ⇒ 得到闭式 \(\binom{x+y+2}{y+1} - 1\)
5. 对 \(10^9+7\) 取模 ⇒ 预处理阶乘和逆元即可 \(O(1)\) 回答每个查询
